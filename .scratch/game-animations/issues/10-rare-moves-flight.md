# 10：少見動作的飛行

**要建置什麼：** 同一影格內會移動兩次的少見動作也有看得懂的演出：瞄準把牌從牌組頂放到牌組底、卡片放回牌組頂或底、洗牌。這類動作會多錄一個影格補上，避免前後影格比對只看到起點與終點（見 ADR-0001 的後果）。

**Blocked by（被誰阻擋）：** 02、03

**Status：** ready-for-agent

- [x] 瞄準時看到牌組頂的牌飛到牌組底
- [x] 放回牌組頂或底的效果有對應的飛行
- [ ] 洗牌有簡短的演出（遊戲進行中沒有任何洗牌的規則，只有開局洗牌，併入票券 12）
- [x] 這些動作各自多錄影格，引擎端測試涵蓋影格順序

## Comments

- 瞄準把牌組頂的牌放到牌組底：牌組只有張數、沒有卡片，位置的變化在桌面上看不出來，所以新增專屬的 `aimSwap` 影格類型，介面在牌組堆上畫一張牌背繞出來再塞到底下。
- 手牌放到牌組頂或底（交涉、電弧、瞄準升級後）的飛行在票券 01、03 就已經是通用的，這張票券只補了測試。頂與底在畫面上看起來一樣，因為牌組是一疊蓋著的牌。
- 洗牌：引擎裡沒有遊戲進行中的洗牌，只有開局洗牌，所以放到票券 12。
- 瀏覽器實跑（臨時情境頁面，已刪除）：遊俠瞄準換牌時，牌組堆上看得到飛出的牌背；因為我方牌組在畫面最下方，會被「動畫播放中」的面板遮住一部分。
