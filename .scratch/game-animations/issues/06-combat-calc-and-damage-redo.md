# 06：攻守拼招與傷害重做

**要建置什麼：** 攻守拼招時，算式框改成逐項出現：先對方總攻，再我方總防，最後傷害數字重重落下。受傷的一方，牌背從牌組逐張飛進怒氣區，第一張落下時整塊畫面震動並浮出傷害數字。沒有傷害的一方顯示綠色的 0，不震動。

**Blocked by（被誰阻擋）：** 03

**Status：** ready-for-agent

- [ ] 算式依總攻、總防、傷害的順序逐項出現，傷害數字有重落的效果
- [ ] 受傷一方第一張牌落進怒氣區時整塊震動並浮出傷害數字
- [ ] 沒有傷害的一方顯示綠色的 0，且不震動
- [ ] 色彩語意統一：攻擊橙紅、防禦藍、傷害紅、成功綠
- [ ] 算式上的數字與實際扣血張數一致（現有測試維持通過）
