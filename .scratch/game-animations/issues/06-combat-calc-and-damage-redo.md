# 06：攻守拼招與傷害重做

**要建置什麼：** 攻守拼招時，算式框改成逐項出現：先對方總攻，再我方總防，最後傷害數字重重落下。受傷的一方，牌背從牌組逐張飛進怒氣區，第一張落下時整塊畫面震動並浮出傷害數字。沒有傷害的一方顯示綠色的 0，不震動。

**Blocked by（被誰阻擋）：** 03

**Status：** ready-for-agent

- [x] 算式依總攻、總防、傷害的順序逐項出現，傷害數字有重落的效果
- [x] 受傷一方第一張牌落進怒氣區時整塊震動並浮出傷害數字
- [x] 沒有傷害的一方顯示綠色的 0，且不震動
- [x] 色彩語意統一：攻擊橙紅、防禦藍、傷害紅、成功綠
- [x] 算式上的數字與實際扣血張數一致（現有測試維持通過）

## Comments

- 算式六個項目（兩條算式各三項）依序出現，傷害數字從放大處重重落下；整段約 1.8 秒，在算式影格的 2 秒內播完。時間隨播放速度等比縮放。
- 受傷一方的震動與傷害數字，延遲到第一張牌落進怒氣區才開始（延遲取自引擎的飛行時序）。
- 攻擊、防禦的淺色文字改用共用變數，卡面的攻防數字、總攻總防、算式用同一組顏色。
- 以瀏覽器實跑（標準速度）看過算式逐項出現的畫面。震動與傷害數字的延遲只做了程式與型別檢查，沒有在實跑中抓到畫面；快速速度下算式最後一項可能被縮短的影格切到，沒有逐一確認。
