# 08：數值變化動畫

**要建置什麼：** 生命（牌組張數）、怒氣、經驗、總攻、總防、增益持續時間指示物變動時，對應的數字閃一下並顯示差值（例如 −3、+1），讓玩家注意到哪個數字變了。靠比對相鄰影格的數字，不需要改引擎。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [x] 生命、怒氣、經驗的數字變動時閃爍並顯示差值
- [x] 總攻、總防變動時閃爍並顯示差值
- [ ] 增益指示物變動時有提示（變動的指示物會顯示差值；指示物歸零而離場的增益、剛放入的增益沒有差值提示，目前資料裡也沒有增益卡，只有單元測試涵蓋）
- [x] 沒有變動時不閃爍
- [x] 色彩語意與統一的動畫語彙一致

## Comments

- 數值差值由「相鄰兩個影格的桌面」算出，不用改引擎：新增一個純函式回傳生命、怒氣、經驗、總攻、總防與增益指示物的差值，測試用引擎真實錄出的影格，預期值取自傷害算式影格與歸還前的區域張數。
- 顯示位置：生命與經驗在標頭的標籤上，怒氣在牌堆下方，總攻總防在戰鬥區的合計框；生命、總攻、總防依正負上色，怒氣與經驗用強調色。
- 順手修了一個之前票券留下的問題：新的一批影格剛到、還沒開始播的那一次繪製，畫面會短暫顯示最終桌面，飛行和數值差值也會拿最終桌面當「上一個畫面」去比，第一個影格的方向可能是反的。現在這段空檔維持上一個桌面。我沒有辦法用截圖證明修之前一定會出錯，只確認修了之後三種速度都能正常打完一局、沒有錯誤。
- 瀏覽器實跑（臨時情境頁面，已刪除）看過生命、經驗、總攻、總防的差值顯示。增益指示物沒有實際畫面。
