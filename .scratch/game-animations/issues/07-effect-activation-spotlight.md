# 07：通用發動演出

**要建置什麼：** 卡片效果發動時，玩家看到該卡從原位置浮到畫面中央放大、桌面壓暗，並顯示效果說明，然後縮回去繼續。所有卡片共用同一套演出，不做每張卡客製特效。與支付費用、後續效果各自分段播放。

**Blocked by（被誰阻擋）：** 02、05

**Status：** ready-for-agent

- [x] 任何卡片效果發動都會有中央放大演出，並顯示效果說明（範圍：需要付費的選用效果、覆蓋反應、伏擊、二連矢、電弧、凡骨的意志、順手牽羊、交涉；之後新增的免費效果要在腳本裡補呼叫，角色效果沒有，已接受）
- [x] 沿用追擊判定建立的中央放大與聚焦遮罩基本動作
- [x] 發動、付費、效果結果各自分段，依序播放
- [x] 對手發動時，若該卡本來就是公開的才顯示正面（現況：發動的牌一律顯示正面，因為發動與紀錄本來就公開卡名，已接受）
- [x] 快速模式與關閉動畫對發動演出同樣有效（時間依速度倍率縮放；只在標準速度下看過畫面）

## Comments

- 引擎新增 `activate` 影格類型：發動時還沒付費、效果還沒生效，帶著發動者、那張牌的實體編號與卡片編號。需要付費的選用效果（含家族相片、招財貓這類）一律經過同一個發動點；不需付費的效果要在腳本裡明確呼叫，所以只涵蓋上面列出的幾張，之後新增的卡片要記得補，這是目前的限制。
- 中央放大元件已改成同時支援追擊翻牌、判定結果、效果發動三種。發動時牌從它所在的位置放大到中央，下方顯示本次說明與完整效果文字，停約 0.75 秒再縮回原位。
- 瀏覽器實跑（臨時的情境頁面，已刪除）確認：伏擊與火球的發動畫面看得到放大的牌、「效果發動」標題與效果說明。覆蓋反應的畫面沒有實際看到，只有引擎端測試涵蓋。
- 發動影格公開了那張牌的卡片編號。覆蓋反應與紀錄本來就會公開卡名，所以沒有新增外洩的資訊。
