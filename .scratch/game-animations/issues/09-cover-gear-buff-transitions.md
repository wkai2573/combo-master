# 09：覆蓋、裝備與增益的進出場

**要建置什麼：** 經驗卡被覆蓋時玩家看到它翻成背面，覆蓋反應效果緊接著各自一段。裝備與增益進場時有飛入，離場時有淡出，增益到期離場能看出是哪一張。

**Blocked by（被誰阻擋）：** 02、04

**Status：** ready-for-agent

- [x] 經驗卡被覆蓋時有翻面演出
- [x] 覆蓋反應效果接在翻面之後、各自分段
- [x] 裝備與增益進場有飛入，離場有淡出
- [x] 對手的覆蓋經驗卡維持隱藏，翻面時不洩漏牌面

## Comments

- 大部分在前面的票券已經自然涵蓋：裝備與增益進場（手牌飛進裝備區）、增益到期（從增益區飛進經驗區）、覆蓋翻面與覆蓋反應分段（票券 02）。這張票券補上的是離場與憑空出現：離開遊戲的牌在原地淡出，憑空出現的牌（例如額外卡）在原地淡入。
- 測試：打出裝備的飛行（對手視角看到的是牌背翻成正面）；增益到期與離場、憑空出現是用手動改過的桌面丟給飛行比對，沒有走真正的遊戲流程，因為目前資料裡沒有增益卡。
- 淡出、淡入的實際畫面沒有看到，只確認型別與程式；打出裝備的飛行用臨時情境頁面看過（家族相片從手牌飛向裝備區）。
- 已知限制：從牌組或棄牌堆直接離場的牌沒有淡出（沒有可用的起點位置）。
