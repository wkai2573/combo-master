# 11：回合與階段橫幅

**要建置什麼：** 每回合開頭，畫面中央顯示「第 N 回合・你先攻／對手先攻」橫幅；追擊、傷害計算等戰鬥主要階段，顯示約 0.6 秒的階段橫幅。只放在這些時機，不是每個階段都放，避免拖慢節奏。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [x] 每回合開頭顯示回合數與先後攻
- [x] 追擊、傷害計算等戰鬥主要階段顯示橫幅，約 0.6 秒
- [x] 其他階段不顯示橫幅
- [x] 橫幅風格使用統一的動畫語彙
- [x] 快速模式與關閉動畫對橫幅同樣有效

## Comments

- 新增 `banner` 影格類型：回合開頭（帶回合數與先攻方，介面依自己的視角顯示「你先攻」或「對手先攻」）、追擊階段、傷害計算。原本放在回合開頭與追擊階段的 `phase` 影格改成橫幅，回合結束的 `phase` 影格維持不變；傷害計算前多一個橫幅影格。
- 橫幅影格 0.7 秒，動畫 0.65 秒，隨播放速度等比縮放。抽牌、爆發、增益等其他階段沒有橫幅（測試確認）。
- 瀏覽器實跑（臨時情境頁面，已刪除）只看到回合開頭的「第 1 回合・你先攻」橫幅。追擊、傷害計算的橫幅只有引擎端測試涵蓋，畫面沒有實際看到；快速速度也沒看過。
- 橫幅出現時，戰鬥區上方仍會顯示該影格的說明文字，內容有些重複。
