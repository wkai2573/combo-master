# 05：追擊判定重做（含中央放大與聚焦遮罩）

**要建置什麼：** 追擊判定時，翻開的牌從牌組堆飛到畫面中央，桌面壓暗約 50%，翻成正面放大，並顯示「成功／失敗」。成功時牌飛進戰鬥區成為追擊卡，失敗時飛進手牌。這張票券同時建立「中央放大加聚焦遮罩」這個共用基本動作，之後的發動演出沿用。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [ ] 判定牌從牌組堆飛到中央、翻面放大、顯示成功或失敗
- [ ] 成功時牌飛進戰鬥區成為追擊卡，失敗時飛進手牌
- [ ] 中央放大期間桌面壓暗約 50%，結束後恢復
- [ ] 中央放大做成可被其他演出重用的基本動作
- [ ] 瞄準換牌（把牌組頂放到牌組底再判定下一張）的現有行為不退步
- [ ] 現有追擊相關測試仍然通過，並補上新演出對應的影格測試
