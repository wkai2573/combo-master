# 05：追擊判定重做（含中央放大與聚焦遮罩）

## Comments

- 「中央放大加聚焦遮罩」是獨立元件（桌面壓暗約 50%、牌放大在中央、上方一行說明），但目前只認追擊翻牌與結果的影格類型；票券 07 要先把它改成吃「要顯示的牌與說明」才能沿用。
- 判定結果影格：牌在中央停約 0.6 秒，顯示成功（綠）或失敗（紅），然後從中央飛向去處（成功進戰鬥區，失敗進手中；對手的手牌飛到途中翻回牌背）。
- 瞄準換牌沿用原本的「放到牌組底」影格，行為沒有改。
- 以瀏覽器實跑（快速速度）確認：翻牌影格看得到中央放大與「追擊判定」，結果影格看得到「追擊成功！」，遮罩淡出時牌往戰鬥區飛。失敗（飛進手中）與對手手牌的情況沒有實際看到。
- 追擊判定的說明文字現在同時出現在中央與戰鬥區上方的標題列，內容重複，之後可以考慮只留一處。
