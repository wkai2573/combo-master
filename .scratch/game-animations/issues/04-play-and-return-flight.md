# 04：出招與歸還的飛行

**要建置什麼：** 玩家出招時看到牌從手牌飛到戰鬥區；對手出招時，牌從對手手牌的位置飛出，並在途中翻成正面。回合結束時，招式與追擊卡依序飛進經驗區。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [x] 自己出招時牌從手牌飛到戰鬥區
- [x] 對手出招時牌從對手手牌位置飛出且途中翻成正面
- [x] 歸還階段招式與追擊卡依序飛進經驗區
- [x] 既有的「剛出的牌短暫發光」效果仍然保留
- [x] 飛行清單測試涵蓋出招與歸還的相鄰影格

## Comments

- 出招的飛行在票券 01 就已經是通用的；這張票券補上的是歸還：招式與追擊卡視為同一起點，先後（依進入經驗區的順序）飛進，不會同時出發。同一位玩家、不同起點的飛行（例如抽牌與別處回手）仍然各自同時出發。
- 「剛出的牌短暫發光」沿用原本的設定，牌落地後發光。
- 瀏覽器實跑只確認單機有飛行、沒有錯誤；出招與歸還的實際畫面沒有逐一確認，截圖裡看得到飛行中的牌，但沒辦法從單張截圖確認順序。
