# 01：抽牌飛行（曳光彈）

**要建置什麼：** 玩家在對戰畫面上看到每個人都有實體牌堆：牌組（疊出厚度、顯示張數）、棄牌區（頂牌正面）、怒氣區（疊起來）。抽牌階段與效果抽牌時，卡片從牌組逐張飛進手牌：自己抽的是正面，對手抽的是牌背。這是整個功能的第一條完整路徑：牌堆位置、蓋滿畫面的飛行圖層、相鄰影格比對推導飛行（見 ADR-0001）、影格的卡片可見性欄位（由主機依各自視角產生，不外洩對手牌面），以及統一的動畫時長、緩動與配色變數。聯機時對手看到同樣的演出，不新增訊息類型。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] 每位玩家的區塊有牌組、棄牌區、怒氣區的實體牌堆，其餘版面不動
- [x] 抽牌時卡片從牌組逐張飛進手牌；自己是正面、對手是牌背
- [x] 飛行由相鄰兩個影格推導，引擎不新增卡片移動事件
- [x] 影格帶卡片可見性，聯機時對手看不到的牌面不會被傳過去
- [x] 時長、緩動、配色集中成一組共用變數
- [x] 標準、快速、關閉動畫三檔速度與跳過動畫對飛行同樣有效
- [x] 引擎端測試：抽牌後錄到的影格與可見性正確、沒開動畫不錄影格；飛行清單測試：給定相鄰影格輸出正確的起訖區域
- [x] 以瀏覽器實跑驗證單機與聯機畫面（單機已用瀏覽器實跑確認有飛行、無錯誤；聯機與快速、跳過尚未實測）

## Comments

- 影格的卡片可見性沿用既有的檢視層遮蔽（對手手牌、怒氣與覆蓋經驗卡的牌面本來就是 null），不新增欄位；飛行清單依此決定起訖是否正面，怒氣區與覆蓋中的牌一律顯示牌背。
- 飛行比對是通用的，所以出招、歸還、受傷、棄牌等卡片移動在這張票券完成後已經會飛；03、04 要處理的是它們的細節（棄牌翻面、整段不超過 1.5 秒、對手出招途中翻面等）與驗證。
- 已知待處理：棄牌堆的頂牌在飛行開始時就已經顯示新牌（03）；捲動或縮放視窗發生在兩個影格之間時，起點位置可能過時；憑空出現與離開遊戲的卡（`spawn`／`gone`）目前不飛，維持原本的淡入（09）。
