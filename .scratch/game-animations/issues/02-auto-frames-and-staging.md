# 02：影格由引擎自動保證，並分段播放

**要建置什麼：** 玩家在任何會改變卡片位置的動作之後，都會看到對應的演出，不會因為新增卡片效果而漏掉。引擎在卡片移動或寫入紀錄時，於該步驟結束自動錄一個影格；原有的手動標記保留，用來指定特殊演出類型。連「覆蓋」這種只改旗標、沒有移動的動作也納入。同一步驟裡連續的事（發動、付費、抽牌）各自一段，依序播放。以支付費用驗證：蓋 X 時經驗卡翻成覆蓋，怒 X 時怒氣區的牌飛進棄牌區，之後觸發的覆蓋反應再各自一段。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [x] 卡片移動或寫入紀錄後，步驟結束時自動有影格
- [x] 覆蓋動作也會錄影格並有翻面演出
- [x] 支付費用（蓋 X、怒 X）有演出，且與後續效果分段播放
- [x] 現有手動標記的特殊演出類型（追擊翻牌、傷害算式、收招等）行為不變
- [x] 沒開動畫（壓測與測試）時不產生影格、沒有額外成本
- [x] 引擎端測試：每個改變卡片位置的操作至少錄到一個影格；同一步驟的多件事錄成多個影格且順序正確

## Comments

- 做法：引擎記錄自上個影格以來的卡片移動與紀錄次數；玩家要回應之前（或遊戲結束時）若還有未呈現的變化，就補錄一個新的 `step` 影格。付費、發動、覆蓋反應另外在各自的步驟結束時明確補錄，所以彼此分段。
- 驗證：新增的測試用 12 局隨機對戰，確認玩家每次要回應之前，最後一個影格的桌面一定等於真實桌面。
- 覆蓋的翻面目前是原地快速翻轉一下（瀏覽器實跑只確認沒有錯誤，沒有實際看到覆蓋發生）；更完整的覆蓋演出（含覆蓋反應）在票券 09。
- 「發動」那一段目前只有說明文字，沒有放大卡片，等票券 07。
