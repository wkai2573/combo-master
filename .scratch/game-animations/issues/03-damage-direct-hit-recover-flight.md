# 03：受傷、直擊、回復的逐張飛行

**要建置什麼：** 玩家受到傷害時，看到牌背從牌組逐張飛進怒氣區；受到直擊或牌被丟棄時，牌在飛行途中翻成正面並逐張飛進棄牌區（棄牌區是公開的）；回復時怒氣區的牌飛回牌組頂。一次移動很多張時逐張飛出、間隔很短，張數多時自動加快，整段不超過約 1.5 秒。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [x] 受傷時牌背逐張飛進怒氣區，雙方看到的都是牌背
- [x] 直擊與丟棄時牌途中翻正面飛進棄牌區
- [x] 回復時怒氣區的牌飛回牌組頂
- [x] 多張牌逐張飛出，張數多時加快，整段不超過約 1.5 秒
- [x] 對手視角下怒氣區內容仍然隱藏，只看得到張數
- [x] 引擎端測試與飛行清單測試涵蓋多張牌的順序與張數

## Comments

- 飛行時序集中在引擎的 `FLY`：每張 420ms、同組間隔 90ms，整批最多 1.5 秒，張數多時壓縮（每張最短 150ms）。
- 引擎錄影格時，會把「這個影格裡的飛行要播多久」算進停留時間（多留 120ms 緩衝），不會被下一個影格截斷。聯機時對手收到的影格已經帶著這個時間。
- 棄牌堆的頂牌在整批牌落地前先藏起來，落地後才顯示新的頂牌（票券 01 的已知待處理項目，已處理）。
- 瀏覽器實跑只確認單機有飛行、沒有錯誤；直擊、受傷、回復的實際畫面沒有逐一看過截圖。
