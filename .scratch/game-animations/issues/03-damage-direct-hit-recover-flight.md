# 03：受傷、直擊、回復的逐張飛行

**要建置什麼：** 玩家受到傷害時，看到牌背從牌組逐張飛進怒氣區；受到直擊或牌被丟棄時，牌在飛行途中翻成正面並逐張飛進棄牌區（棄牌區是公開的）；回復時怒氣區的牌飛回牌組頂。一次移動很多張時逐張飛出、間隔很短，張數多時自動加快，整段不超過約 1.5 秒。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [ ] 受傷時牌背逐張飛進怒氣區，雙方看到的都是牌背
- [ ] 直擊與丟棄時牌途中翻正面飛進棄牌區
- [ ] 回復時怒氣區的牌飛回牌組頂
- [ ] 多張牌逐張飛出，張數多時加快，整段不超過約 1.5 秒
- [ ] 對手視角下怒氣區內容仍然隱藏，只看得到張數
- [ ] 引擎端測試與飛行清單測試涵蓋多張牌的順序與張數
