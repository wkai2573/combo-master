## 白板卡數值

- 36 張白板卡用同一條循環：攻擊依 60、52、44、35、26、17、08 遞減，過 08 回到 60，數字是「攻擊、防禦」。
- 黑桃、紅心、梅花、方塊分別錯開 0、2、4、6 格，同連擊值的 4 張一定互不相同。
- 只改這 36 張，效果卡數值不動。
- 數值的來源是卡表網頁：改卡表資料庫，再跑 `npm run table` 同步。

## 預設牌組

- 每位角色：職業效果招式各 3 張，生命藥水 2 張，武器放木棍、防具放皮甲、飾品放職業飾品各 1 張。
- 法師的飾品放星界法典，不放冰與雷之曲。
- 勇者不放嘲諷與盾擊；後人嘲諷 1 張、盾擊 3 張。
- 勇者、後人、商人的生命藥水改放 1 張，避免連擊值 5 的效果卡超過 7 張。
- 連擊值盡量平均（不是硬性規定），白板卡補滿剩下的格子，同一連擊值裡依角色的攻守傾向挑：

| 角色 | 傾向 |
|---|---|
| 勇者 | 強偏攻 |
| 後人 | 強偏守 |
| 刺客 | 偏攻 |
| 先人 | 均衡 |
| 商人 | 均衡（攻守接近） |
| 法師 | 偏攻 |
| 遊俠 | 均衡 |

## +X+Y

- 範圍：卡文、角色文字、卡片撰寫規範、遊戲紀錄的加成訊息。更新日誌的歷史紀錄不動。
- 寫法：兩個數字都寫，沒有的那邊寫 0，減少用「−」，例如 `+0+2`、`−3+0`、`+0−4X`、`+X+X`。條件句（總攻擊達 15 以上時）不改。
- 卡表新增關鍵字「+X+Y」，滑過卡文顯示說明。
