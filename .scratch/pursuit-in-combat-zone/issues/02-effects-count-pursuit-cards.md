# 02：卡效果的「戰鬥區」改為包含追擊卡疊

**要建置什麼：** 電弧、盾擊、凡骨的意志、冰與雷之曲這四張卡的效果，凡是提到戰鬥區的地方，改取戰鬥區（招式卡疊加追擊卡疊）。規格見 `.scratch/pursuit-in-combat-zone/spec.md`。

**Blocked by（被誰阻擋）：** 01

**Status：** resolved

- [x] 電弧：對方戰鬥區招式數量包含追擊成功的招式
- [x] 盾擊：戰鬥區每張招式卡含追擊卡，原始攻擊力小於原始防禦力就提升；追擊卡一落地就適用，結算算進去
- [x] 凡骨的意志：戰鬥區白板卡數量包含追擊卡
- [x] 冰與雷之曲：戰鬥區的卡共有特徵判斷含追擊卡
- [x] 範圍內判定、重複連擊值、[頂]仍然只看招式卡疊，各有測試；歸還順序的程式沒有改動，沒有另外新增測試
- [x] 每張受影響的卡都有測試：追擊成功後計數或提升確實包含追擊卡
- [x] `docs/規則詮釋.md` 第 6、19 條與盾擊的說明同步修改
- [x] 型別檢查與全部測試通過
- [x] 依版本號維護規範升版

## Answer

已於 v0.27.0 生效。電弧、冰與雷之曲改取 `combatZone`；凡骨的意志的白板卡數（`vanillaCount`）改取戰鬥區；盾擊的補攻擊力延伸到追擊卡疊，並計入 `shieldLift`。範圍內、重複連擊值、[頂]、歸還順序仍只看招式卡疊。`docs/規則詮釋.md` 與 `docs/連擊大師.md` 的相關條文已同步。測試在 `tests/pursuitInCombatZone.test.ts`，舊的盾擊測試依新規則改了預期值。

電弧與冰與雷之曲在出招、收招時結算，那時追擊卡疊一定是空的，所以這兩張卡改取戰鬥區後，實際對局的行為不會變，只是定義對齊；凡骨的意志與盾擊在結算總攻防時才看到追擊卡，這兩張才有實際差異。
