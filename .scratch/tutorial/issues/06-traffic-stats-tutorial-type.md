# 06：流量統計的「教學」類型

**要建置什麼：** 流量統計的對戰類型新增「教學」。教學場次的開始與完成記成這個類型，不記成單機；伺服器的事件驗證接受它，仍然拒絕不認得的值；站長的流量統計報表把教學另外列出，不併進單機。戰績驗證不變。伺服器要重新部署才會收這個類型，部署前送出的教學事件會被拒絕，這可以接受；部署是對外動作，由使用者決定何時執行，票券只負責程式與測試。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [ ] 教學場次開始與正常完成時，流量統計收到的對戰類型是「教學」；中途離開不記完成（測試，比照場次統計的測試）
- [ ] 伺服器事件驗證接受「教學」、拒絕不認得的值（測試，比照既有伺服器測試）
- [ ] 流量統計報表把教學另外列出
- [ ] 不自行部署伺服器；完成時提醒使用者需要執行部署
- [ ] `bun run test`、`bun run build` 通過
