# 02：要求出牌、對手照腳本出招、高亮與操作封鎖（電腦版）

**要建置什麼：** 教學腳本支援「要求出牌」與「對手出牌」兩種步驟。對手照腳本回應提示，不用機器人、不用計時器；要求出牌時，玩家只能點擊或拖曳指定的那張手牌到戰鬥區，出別張牌或收招都被拒絕，桌面不變。教學中封鎖其他所有操作（其他手牌、收招按鈕、牌區列表、戰鬥區列表、遊戲紀錄、流程圖、作弊面板），只開放指定的手牌、看卡片說明（滑鼠移上去或長按）、離開按鈕；隱藏「跳過動畫」，保留動畫速度。電腦版畫出高亮：會閃動的虛線外框加光暈，其他地方不壓暗；高亮目標以規格列的抽象名稱描述，由電腦版對應到畫面元素。腳本寫到「範圍內」那一段結束：對手紅心9 → 玩家黑桃1 → 對手黑桃8 → 說明梅花9 不在範圍內 → 玩家紅心2 → 對手梅花7 → 玩家梅花7。說明文字照規格的修正（「AI」改「對手」）。
