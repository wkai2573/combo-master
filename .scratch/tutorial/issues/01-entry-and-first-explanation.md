# 01：教學入口與第一步說明（曳光彈）

**要建置什麼：** 玩家在主畫面「單機練習」下方看到整排寬的「新手教學」按鈕（副標「一步步學會出招與追擊」），按下去直接進入一場教學對局：見習生對教官，雙方手牌與牌組照規格的牌面配置，對手先攻、不洗牌，畫面直接從戰鬥階段開始，不播開局的洗牌與抽牌影格。畫面中央依序顯示腳本開頭的兩段說明（「雙方輪流在可出招的"範圍內"打出招式……」與「由對手先攻……」），點畫面任何地方或按空白鍵、Enter 進入下一步；目前腳本走完就停在最後一步。離開按鈕回主畫面。教學不送出戰績。規格見 `.scratch/tutorial/spec.md`，詞彙見 `GLOSSARY.md`「新手教學」，決策見 ADR 0008。

這張建立之後各票共用的骨架：
- 教學角色（見習生、教官）：依 id 查得到，但不出現在任何角色清單
- 教學腳本的資料格式，這張只需要支援「說明」步驟（文字＋高亮目標欄位先保留，可以先不畫高亮）
- 教學場次：實作既有場次介面，狀態多一份教學進度，提供「進入下一步」
- 戰鬥畫面的教學圖層雛形：說明框、全畫面點擊接收、按鍵處理，只在影格播完時顯示
