# 01：新增 Match 並直接測它

**要建置什麼：** 新增 `src/net/match.ts` 的 `Match`，持有 `Game` 與 `CheatHub`，為兩位玩家同時產生更新。這一票只新增，不改任何使用者。規格見 `.scratch/match/spec.md`，詞彙見 `GLOSSARY.md` 的「對局」。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 介面符合規格草圖；`submit` 與 `cheat` 的拒絕以回傳結果表示，結果帶錯誤說明
- [ ] 每次變化回傳的兩位玩家更新同時產生，影格只被取走一次：連續兩次 `flush` 第二次沒有影格
- [ ] `snapshot` 帶現況視角，不帶影格，也不取走尚未取走的影格
- [ ] 不合法的提交被拒絕，包含還沒輪到、選項不合法，拒絕後桌面不變、影格不被取走
- [ ] 作弊的操作者以參數為準，沒開作弊模式的操作被拒絕；開關寫進紀錄，下一局重新建立就重置
- [ ] `forfeit` 讓對手獲勝，更新帶勝負
- [ ] 隱藏資訊：對手的手牌與怒氣不出現在視角，對手的裏側經驗只有牌背，自己的裏側經驗看得到牌面；作弊檢視只給開啟作弊的那一方
- [ ] `cheatSnapshot` 即時讀取，不快取
- [ ] 以 `scenario` 風格的輔助函式建立指定場面的 `Match`，測試不 mock、不連網
- [ ] 型別檢查、單元測試與機器人壓測通過
- [ ] 純內部新增，依版本號維護規範不升版
