# 01：經驗效果提示

**要建置什麼：** 經驗區裡，「正面朝上且卡文帶 [經]」的卡（我方與對手看得到的正面卡都算，Ex 卡的中毒也算）加上專屬色外框與角落的小 [經] 標記，讓玩家一眼看出哪些**經驗效果**正在生效。滑過那張卡時，卡片說明多一行「經驗效果：生效中」。被覆蓋的卡不顯示任何狀態（那是隱藏資訊），維持現有的灰階加「覆蓋」標籤。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 經驗區中正面朝上且帶 [經] 的卡有外框與小 [經] 標記；不帶 [經] 的卡、被覆蓋的卡都沒有
- [ ] 對手經驗區中看得到的正面 [經] 卡也有同樣標示
- [ ] 標示不只靠顏色（小 [經] 標記色盲也看得出來）
- [ ] 滑過生效中的 [經] 卡時，卡片說明多一行「經驗效果：生效中」；被覆蓋或不在經驗區時不顯示
- [ ] 判斷「是否生效中」抽成純函式並加測試（在經驗區、正面、卡文帶 [經]）
- [ ] 用詞遵守詞彙表：「經驗效果」指 [經] 效果，「覆蓋反應」只指被覆蓋時觸發的那一類
