# 01：經驗效果提示

**要建置什麼：** 經驗區裡，「正面朝上且卡文帶 [經]」的卡（我方與對手看得到的正面卡都算，Ex 卡的中毒也算）加上專屬色外框與角落的小 [經] 標記，讓玩家一眼看出哪些**經驗效果**正在生效。滑過那張卡時，卡片說明多一行「經驗效果：生效中」。被覆蓋的卡不顯示任何狀態（那是隱藏資訊），維持現有的灰階加「覆蓋」標籤。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] 經驗區中正面朝上且帶 [經] 的卡有外框與小 [經] 標記；不帶 [經] 的卡、被覆蓋的卡都沒有
- [x] 對手經驗區中看得到的正面 [經] 卡也有同樣標示
- [x] 標示不只靠顏色（小 [經] 標記色盲也看得出來）
- [x] 滑過生效中的 [經] 卡時，卡片說明多一行「經驗效果：生效中」；被覆蓋或不在經驗區時不顯示
- [x] 判斷「是否生效中」抽成純函式並加測試（在經驗區、正面、卡文帶 [經]）
- [x] 用詞遵守詞彙表：「經驗效果」指 [經] 效果，「覆蓋反應」只指被覆蓋時觸發的那一類

## Comments

- 判斷抽成純函式並加測試：標籤以底線分隔，單寫的經驗效果標籤與和費用併寫的標籤都算；只有起手或發動標籤的卡不算；看不到牌面或覆蓋中的卡不算。
- 瀏覽器實測：在 1920×950 暫時把經驗區塞成 5、14、24 張混合卡測過，測完已還原。單列、兩列與重疊三種狀態下，帶 [經] 的正面卡都有青色外框與左下角 [經] 標記，覆蓋中的 [經] 卡沒有標示；滑過生效中的卡，說明欄出現「經驗效果：生效中」，滑過沒有經驗效果的卡則沒有。
- 展開的牌區面板在展開經驗區時也套用同一套提示。對手經驗區的提示共用同一個元件，沒有另外實測。
- 限制：外框色是青色，和法師卡的藍色邊框接近，主要靠左下角的 [經] 標記區分。固定住的說明在那張卡被覆蓋後，狀態行不會跟著消失，這只影響自己的牌，不洩漏資訊。
