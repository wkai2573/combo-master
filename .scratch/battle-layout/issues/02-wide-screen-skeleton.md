# 02：寬螢幕骨架：不捲動的三列版面

**要建置什麼：** 可視區寬 ≥ 1200 且高 ≥ 800 時，對戰畫面改成全寬三列加一條提示欄，整頁不捲動（以 1920×1080 的可視區、高約 950 為設計基準，卡牌尺寸用 CSS 變數縮放）：

```
頂欄＋步驟列
對手面板
[ 卡片說明 | 戰鬥區 | 遊戲紀錄 ]
提示欄（固定高約 56px）
我方面板
```

原本右側欄的卡片說明與遊戲紀錄搬到戰鬥區左右兩旁。提示面板不再黏在畫面底，改成固定的提示欄。整頁唯一的捲軸是紀錄欄自己的內部捲動（自動捲到底）。低於斷點時，仍是現有版面。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 寬 ≥ 1200 且高 ≥ 800 時，整頁沒有捲軸（紀錄欄內部除外）
- [ ] 卡片說明在戰鬥區左旁，遊戲紀錄在右旁，右側 300px 欄不再存在
- [ ] 提示面板在提示欄中，選牌、確認、等待對手、動畫播放中都在同一位置顯示
- [ ] 低於斷點時維持現有版面（窄螢幕版另見 08）
- [ ] 卡牌尺寸由 CSS 變數決定，高度在 800 到 1080 之間都不捲動
- [ ] 動畫演出（橫幅、中央放大、卡片飛行）在新版面下位置正確
- [ ] 瀏覽器實測 1920×1080 與 1440×900 兩種可視區
