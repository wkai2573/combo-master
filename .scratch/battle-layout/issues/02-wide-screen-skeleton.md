# 02：寬螢幕骨架：不捲動的三列版面

**要建置什麼：** 可視區寬 ≥ 1200 且高 ≥ 800 時，對戰畫面改成全寬三列加一條提示欄，整頁不捲動（以 1920×1080 的可視區、高約 950 為設計基準，卡牌尺寸用 CSS 變數縮放）：

```
頂欄＋步驟列
對手面板
[ 卡片說明 | 戰鬥區 | 遊戲紀錄 ]
提示欄（固定高約 56px）
我方面板
```

原本右側欄的卡片說明與遊戲紀錄搬到戰鬥區左右兩旁。提示面板不再黏在畫面底，改成固定的提示欄。整頁唯一的捲軸是紀錄欄自己的內部捲動（自動捲到底）。低於斷點時，仍是現有版面。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] 寬 ≥ 1200 且高 ≥ 800 時，整頁沒有捲軸（紀錄欄內部除外）
- [x] 卡片說明在戰鬥區左旁，遊戲紀錄在右旁，右側 300px 欄不再存在
- [x] 提示面板在提示欄中，選牌、確認、等待對手、動畫播放中都在同一位置顯示
- [x] 低於斷點時維持現有版面（窄螢幕版另見 08）
- [x] 卡牌尺寸由 CSS 變數決定，高度在 800 到 1080 之間都不捲動
- [ ] 動畫演出（橫幅、中央放大、卡片飛行）在新版面下位置正確
- [x] 瀏覽器實測 1920×1080 與 1440×900 兩種可視區

## Comments

- 以 `useWide` 判斷是否為寬螢幕版（可視區寬 ≥ 1200 且高 ≥ 800），寬螢幕與現有版面各渲染各自的骨架，低於斷點的版面沒有動。
- 瀏覽器實測（單機練習、開局反擊步驟）：1920×950 與 1440×800 都沒有整頁捲軸；1000×700 仍是現有版面。
- 玩家面板為了擠進高度，暫時用 grid 把手牌排到右邊，是過渡做法；單橫列與牌堆順序仍由 04 處理。
- 卡牌尺寸：戰鬥區與手牌的大卡用 `--mdw`、`--mdh` 兩個變數，高度 ≤ 920 與 ≤ 840 各縮一檔。小卡尺寸還是固定值，未變數化。
- 未驗收：動畫演出（橫幅、中央放大、卡片飛行）在新版面下的位置只看了程式，沒有實際播放確認。
- 已知限制（交給 03）：有裝備／增益時左欄會變高，擠壓戰鬥區；提示有選項卡時提示欄會長高（約 122px，已縮成小卡並排）；手牌太多時目前是列內橫向捲動（06 處理）。
