# 07：牌區就地展開

**要建置什麼：** 點棄牌區、怒氣區或經驗區標籤時，不再跳出置中視窗，改成貼著該區的展開面板，不推擠任何其他區域，點外面或按 Esc 關閉。對手的怒氣區看不到內容，點它不展開。

**Blocked by（被誰阻擋）：** 04

**Status：** ready-for-agent

- [ ] 點我方、對手的棄牌區與經驗區，展開面板貼著該區出現，列出全部牌（覆蓋中的對手經驗卡顯示牌背）
- [ ] 點我方怒氣區可展開；點對手怒氣區不展開
- [ ] 展開與關閉時，其他區域的位置與大小都不變
- [ ] 點面板外或按 Esc 關閉；Esc 同時也用於取消固定的卡片說明，兩者不互相干擾
- [ ] 展開面板裡滑過卡片，說明欄照常顯示
- [ ] 置中的牌區視窗不再使用
