# 07：牌區就地展開

**要建置什麼：** 點棄牌區、怒氣區或經驗區標籤時，不再跳出置中視窗，改成貼著該區的展開面板，不推擠任何其他區域，點外面或按 Esc 關閉。對手的怒氣區看不到內容，點它不展開。

**Blocked by（被誰阻擋）：** 04

**Status：** ready-for-agent

- [x] 點我方、對手的棄牌區與經驗區，展開面板貼著該區出現，列出全部牌（覆蓋中的對手經驗卡顯示牌背）
- [x] 點我方怒氣區可展開；點對手怒氣區不展開
- [x] 展開與關閉時，其他區域的位置與大小都不變
- [x] 點面板外或按 Esc 關閉；Esc 同時也用於取消固定的卡片說明，兩者不互相干擾
- [ ] 展開面板裡滑過卡片，說明欄照常顯示
- [x] 置中的牌區視窗不再使用

## Comments

- 定位規則抽成純函式並加測試：下方放得下就放在錨點下方，否則放上方；上下都放不下時選空間較大的一邊；左右夾在可視區內。我方的牌區在畫面下半，所以面板往上展開；對手的往下展開，都不會蓋住被點的那個牌堆。
- 瀏覽器實測（1920×950，單機練習，開局各區都是空的）：我方棄牌與怒氣、對手棄牌與經驗區都貼著該區展開；對手怒氣區點了不展開；每次展開時，各列面板高度都和展開前相同；點面板外面會關閉。Esc 先關閉展開的牌區，再按一次才取消固定的卡片說明。
- 展開面板是貼著該區定位的浮層，會暫時蓋住其他區域，但不推擠任何東西；展開期間面板外的點擊只用來關閉，不會同時觸發底下的操作。
- 未驗收：區域裡有牌時的外觀（只測了空的區域，牌的排列沿用原本的小卡）；面板內滑過卡片時說明欄是否照常顯示，只確認元件與之前相同。
