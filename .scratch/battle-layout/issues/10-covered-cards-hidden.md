# 10：覆蓋的經驗卡對雙方都隱藏

**要建置什麼：** 經驗區裡覆蓋的卡，雙方都只看到「?」牌背，不公開也不能查看，擁有者自己也一樣（決策見 ADR 0002）。覆蓋的卡不能滑過查看或固定說明，就地展開的經驗區面板裡也是「?」牌背；牌背上不再有「覆蓋」字樣與灰階效果，統一用跟其他隱藏牌一樣的「?」。冰霜護甲「選 2 張覆蓋的經驗卡捨棄」變成盲選：提示面板列出對應數量的「?」牌背，經驗區裡那些覆蓋卡也發光可以直接點，兩邊都能選。覆蓋的卡被捨棄進棄牌區或被打開時才公開。規則詮釋同步更新。

**Blocked by（被誰阻擋）：** 09

**Status：** ready-for-agent

- [x] 引擎產生的視角裡，覆蓋的卡不帶牌面，雙方視角一致，聯機傳送的影格也一樣
- [x] 經驗區裡覆蓋的卡顯示「?」牌背，沒有「覆蓋」字樣與灰階；不能滑過查看或固定說明
- [ ] 就地展開經驗區時，覆蓋的卡是「?」牌背
- [x] 冰霜護甲的捨棄選項不帶牌面：提示面板列出對應數量的「?」牌背，經驗區裡覆蓋卡發光可點，兩邊都能選
- [ ] 覆蓋的卡被捨棄進棄牌區或被打開時才公開，卡片飛行與翻面演出仍然正確
- [x] 經驗效果提示對覆蓋的卡不顯示（已是如此，確認不退步）
- [x] 新增視角的測試：覆蓋卡在雙方視角都沒有牌面，打開後有；冰霜護甲選項不洩漏牌面
- [x] 規則詮釋文件說明覆蓋的卡對雙方隱藏、離開經驗區才公開

## Comments

- 實作只動引擎視角（`viewFor`：覆蓋就不帶牌面）與提示選項（`cardOpt`：覆蓋的經驗卡回傳 `hidden`，沒有 `cardId` 與卡名）。聯機與動畫影格共用同一條視角規則，所以協定不用改。介面端 `CardFace` 拿掉 `covered` 屬性與灰階、「覆蓋」字樣樣式，`PromptPanel` 把 `hidden` 選項畫成「?」牌背。
- 瀏覽器實測（單機練習，暫時塞牌與提示後已還原）：覆蓋卡是「?」牌背，沒有灰階與字樣；滑過覆蓋卡說明欄沒有內容，滑過正面卡有說明。盲選提示：提示面板顯示「?」牌背，經驗區對應的覆蓋卡同時發光，兩邊都能選、選取狀態同步、確認數正確。
- 覆蓋反應被觸發時，紀錄仍寫卡名（維持現況）：觸發當下那張卡還是正面，效果本身也是公開事件。
- 未勾的兩項沒有實際確認：就地展開經驗區面板（畫的是同一份視角資料，預期是牌背，但沒有打開看）；覆蓋卡被捨棄或打開時，卡片飛行與翻面演出的畫面（只在影格層測了牌面可見性）。另外盲選提示是以暫時塞的提示驗證，沒有真的打出冰霜護甲走完整流程的畫面（引擎流程有測試）。
