# 10：覆蓋的經驗卡對雙方都隱藏

**要建置什麼：** 經驗區裡覆蓋的卡，雙方都只看到「?」牌背，不公開也不能查看，擁有者自己也一樣（決策見 ADR 0002）。覆蓋的卡不能滑過查看或固定說明，就地展開的經驗區面板裡也是「?」牌背；牌背上不再有「覆蓋」字樣與灰階效果，統一用跟其他隱藏牌一樣的「?」。冰霜護甲「選 2 張覆蓋的經驗卡捨棄」變成盲選：提示面板列出對應數量的「?」牌背，經驗區裡那些覆蓋卡也發光可以直接點，兩邊都能選。覆蓋的卡被捨棄進棄牌區或被打開時才公開。規則詮釋同步更新。

**Blocked by（被誰阻擋）：** 09

**Status：** ready-for-agent

- [ ] 引擎產生的視角裡，覆蓋的卡不帶牌面，雙方視角一致，聯機傳送的影格也一樣
- [ ] 經驗區裡覆蓋的卡顯示「?」牌背，沒有「覆蓋」字樣與灰階；不能滑過查看或固定說明
- [ ] 就地展開經驗區時，覆蓋的卡是「?」牌背
- [ ] 冰霜護甲的捨棄選項不帶牌面：提示面板列出對應數量的「?」牌背，經驗區裡覆蓋卡發光可點，兩邊都能選
- [ ] 覆蓋的卡被捨棄進棄牌區或被打開時才公開，卡片飛行與翻面演出仍然正確
- [ ] 經驗效果提示對覆蓋的卡不顯示（已是如此，確認不退步）
- [ ] 新增視角的測試：覆蓋卡在雙方視角都沒有牌面，打開後有；冰霜護甲選項不洩漏牌面
- [ ] 規則詮釋文件說明覆蓋的卡對雙方隱藏、離開經驗區才公開
