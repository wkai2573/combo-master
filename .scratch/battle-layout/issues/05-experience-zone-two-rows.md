# 05：經驗區兩列、矮卡與重疊

**要建置什麼：** 經驗區的高度固定。一列放得下時用完整小卡。放不下就分兩列，卡牌變矮，以卡圖為主，其餘資訊（攻／連擊／守、卡名）看空間有餘裕才顯示；先做一版，餘裕的取捨待看實際畫面再調。兩列也放不下時，改成水平重疊，只露出一部分，滑過浮出完整卡。這張同時建立「重疊加滑過浮出」的共用做法，供 06 重用。

**Blocked by（被誰阻擋）：** 04

**Status：** ready-for-agent

- [ ] 經驗區高度固定，卡牌張數增加也不改變面板高度
- [ ] 一列放得下：完整小卡，同現況
- [ ] 一列放不下：分兩列，矮卡至少顯示卡圖
- [ ] 兩列也放不下：水平重疊，滑過浮出完整卡，仍可點選（需要選經驗卡的提示照常運作）
- [ ] 01 的經驗效果提示在矮卡與重疊狀態下仍看得到
- [ ] 覆蓋中的卡在各種顯示狀態下都維持灰階加覆蓋標示
- [ ] 重疊與浮出的滑過互動不受「減少動態」影響，只有過渡動畫會在減少動態時取消
- [ ] 以張數很多的經驗區（例如 20 張以上）實測
