# 06：手牌溢出重疊

**要建置什麼：** 引擎沒有手牌上限，手牌多到寬度不夠時，我方與對手的手牌都水平重疊。我方每張至少露出約 36px，足以辨認數值並點選；滑過浮出完整卡（重用 05 的做法）。可選的手牌滑過仍有抬起回饋，不可選的不動。

**Blocked by（被誰阻擋）：** 05

**Status：** ready-for-agent

- [ ] 手牌放得下時維持現況，不重疊
- [ ] 放不下時水平重疊，我方每張露出至少約 36px，手牌列高度不變
- [ ] 重疊狀態下仍能點選要打出或要選的牌，選中的牌有明顯回饋
- [ ] 滑過浮出完整卡，不受「減少動態」影響；減少動態時只取消過渡動畫
- [ ] 對手手牌（牌背）同樣會重疊
- [ ] 以很多張手牌（例如 15 張以上）實測
