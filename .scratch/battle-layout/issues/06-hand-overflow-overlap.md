# 06：手牌溢出重疊

**要建置什麼：** 引擎沒有手牌上限，手牌多到寬度不夠時，我方與對手的手牌都水平重疊。我方每張至少露出約 36px，足以辨認數值並點選；滑過浮出完整卡（重用 05 的做法）。可選的手牌滑過仍有抬起回饋，不可選的不動。

**Blocked by（被誰阻擋）：** 05

**Status：** ready-for-agent

- [x] 手牌放得下時維持現況，不重疊
- [x] 放不下時水平重疊，我方每張露出至少約 36px，手牌列高度不變
- [ ] 重疊狀態下仍能點選要打出或要選的牌，選中的牌有明顯回饋
- [x] 滑過浮出完整卡，不受「減少動態」影響；減少動態時只取消過渡動畫
- [x] 對手手牌（牌背）同樣會重疊
- [x] 以很多張手牌（例如 15 張以上）實測

## Comments

- 版面判斷抽成純函式（放不放得下、欄距與下限）並加測試。卡寬與可用寬度都用實際量到的值，所以寬螢幕卡牌縮小檔位時也會跟著變。
- 瀏覽器實測：在 1920×950 把手牌暫時塞成 5、9、20 張，測完已還原。5 張並排，9 與 20 張重疊；手牌列高度不變，沒有整頁捲軸；滑過重疊的牌會浮到最上面顯示完整卡。窄螢幕寬度下 20 張也是重疊。
- 滑過與選中的牌浮到最上層，沒有用過渡動畫；可選手牌的抬起過渡在瀏覽器要求減少動態時取消，滑過浮出本身不受影響。
- 重疊的欄距，我方下限 36px、對手 24px。超過下限放不下時（我方在 700px 寬下約 18 張以上）改成手牌列自己橫向捲動，這時會多出一條橫向捲軸。
- 未驗收：重疊狀態下實際點選要打出的牌，只確認了點選的程式接法沒有變，沒有在真的需要選牌的情境下點過；選中的牌有明顯回饋這一項因此沒勾。
- 順手修正：玩家面板的格線改成可以收縮，窄螢幕下手牌列不會再把整個面板撐寬。
- 審查後調整：選中的牌只抬起、不再浮到最上層（否則會蓋住右邊鄰牌而點不到）；觀察卡寬的對象隨第一張牌更換；負邊距只用在寬螢幕版面；手牌列下方多留位置給發光；手牌格不會被壓縮；減少動態的規則只套用在手牌。
- 已知限制（審查指出、沒處理）：滑過的牌浮到最上層時，會蓋住右邊約兩張的露出條，由左往右掃過時要移出它的右緣才點得到，由右往左或從上下方進入沒有這個問題。需要的話之後可改成滑過時把右邊的鄰牌推開。
- 已知限制：手牌與經驗區各自重複了「量寬度再算版面」的做法與間距常數，沒有共用。
