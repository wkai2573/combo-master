# 09：經驗區由左向右放滿再放第二列

**要建置什麼：** 經驗區放不下一列時，改成「第一列由左向右放滿，剩下的放第二列」，兩列的卡都是矮卡。順序是第一列左到右、再第二列左到右，所以最前方仍是第一列最左，最後方是第二列最右，蓋X 從最前面蓋的順序就是這個閱讀順序。兩列也放不下而進入水平重疊時，前半放第一列、後半放第二列，兩列張數相近，各自重疊到放得下。取代 05 的「由上到下再往右」排法。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [x] 一列放得下：同現況，單列完整小卡
- [x] 一列放不下：第一列放滿一列的容量，剩下的放第二列，兩列都是矮卡；第二列張數可以比第一列少
- [ ] 兩列也放不下：前半在第一列、後半在第二列，各自水平重疊，滑過浮出完整卡
- [x] 版面判斷的純函式與測試更新：兩列模式每列的張數、重疊模式的欄距與每列張數
- [ ] 第一列的牌往下展開、第二列的牌往上展開的規則仍然正確
- [x] 蓋X 的順序在畫面上是由左到右、先第一列再第二列
- [x] 以張數很多的經驗區（例如 20 張以上）實測

## Comments

- 版面判斷（`expLayout`）多回傳 `firstRow`（第一列幾張）：單列時等於張數；兩列時是一列的容量；重疊時是 ceil(張數 / 2)，所以前半在第一列、後半在第二列，兩列欄距相同。介面用 `firstRow` 決定哪些牌在第一列（往下展開）、哪些在第二列（往上展開），格線改成逐列排。
- 瀏覽器實測（單機練習，1920×950，暫時塞牌後已還原）：8、9 張時第一列 5 張（該寬度一列容量）、第二列 3、4 張；14 張（前 7 後 7）與 24 張（前 12 後 12）重疊，兩列欄距相同；各種張數經驗區高度都是 106px。
- 未勾的兩項沒有實際測：「兩列也放不下」那項中的滑過浮出完整卡，以及第一列往下、第二列往上展開的行為（展開的樣式沒有改，只是改了哪些牌算第一列）。
