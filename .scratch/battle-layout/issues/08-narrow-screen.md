# 08：窄螢幕版

**要建置什麼：** 可視區寬 < 1200 或高 < 800 時，維持單欄、可捲動的版面（不特別避免捲動），並套用與寬度無關的改動：經驗區兩列加重疊、經驗效果提示、手牌溢出重疊、牌區就地展開。卡片說明與遊戲紀錄收成可開關的抽屜。之後若有實際裝置回饋，再升級成手機直式專屬設計。

**Blocked by（被誰阻擋）：** 04、05、06、07

**Status：** ready-for-agent

- [x] 窄螢幕下單欄、可捲動，沒有橫向捲軸
- [x] 經驗區兩列加重疊、經驗效果提示、手牌重疊、牌區就地展開都與寬螢幕一致（牌堆順序已在 04 完成，兩版共用）
- [x] 卡片說明與遊戲紀錄各有開關，預設收起，開啟時不擋住操作中的提示
- [x] 提示面板在窄螢幕下仍可操作（選牌、確認）
- [x] 瀏覽器實測約 390px 寬（手機）與約 800px 寬（平板）

## Comments

- 窄螢幕版（可視區寬 < 1200 或高 < 800）改成單欄、頁面本身不橫向捲動；原本在 900 到 1200 寬還會出現的右側欄拿掉，說明與紀錄一律收成抽屜。
- 抽屜：頂欄多了「說明」「紀錄」兩個開關，一次開一個，預設收起；抽屜蓋在桌面上方，最高佔桌面區的 40% 且不超過 280px，不會蓋住底部的提示面板。固定一張卡的說明時，說明抽屜會自動打開，因為觸控裝置沒有滑過。
- 寬度 640 以下：牌堆與經驗區分成兩行，經驗區用滿整行；戰鬥區兩方並排，中間的範圍說明移到下方。
- 窄螢幕的提示面板：選項卡排成一列、放不下時橫向捲動，不再佔滿整個畫面。
- 瀏覽器實測：390×800、800×700、1100×700 都沒有橫向捲軸；390 與 800 寬各自動打 120 步（點提示面板的卡與按鈕），過程沒有橫向溢出。暫時注入 20 張經驗卡與 12 張手牌測 390 寬，測完已還原：經驗區與手牌都改成重疊，經驗效果提示沿用同一個元件。
- 未驗收：觸控操作，全部都是用滑鼠點；手機橫向、平板直式等其他尺寸；窄螢幕下卡片飛行與演出的位置；經驗效果提示在窄螢幕的外觀只看了注入卡的截圖，沒有細看。
- 窄螢幕的頂欄加上步驟列在 390 寬佔了約 220px 高，桌面可用空間偏小，之後可考慮收合。
- 審查後調整：自動打開說明抽屜只在新固定一張卡時觸發，不再因為視窗縮放而彈出；窄螢幕的固定說明只在抽屜裡看得到，所以抽屜的關閉與 Esc 會一併取消固定；開關加上 aria-pressed；寬窄兩版共用同一個說明面板元素。
- 沒處理：抽屜開著時，被蓋住的對手面板暫時點不到，要先關抽屜；開著紀錄抽屜時固定一張卡會切到說明抽屜；窄螢幕下卡片飛行與中央放大的位置沒有驗證，這些是固定定位，理論上不受抽屜影響，但沒有實際播放確認。
