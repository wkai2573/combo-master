# 08：窄螢幕版

**要建置什麼：** 可視區寬 < 1200 或高 < 800 時，維持單欄、可捲動的版面（不特別避免捲動），並套用與寬度無關的改動：經驗區兩列加重疊、經驗效果提示、手牌溢出重疊、牌區就地展開。卡片說明與遊戲紀錄收成可開關的抽屜。之後若有實際裝置回饋，再升級成手機直式專屬設計。

**Status：** ready-for-agent

- [ ] 經驗區兩列加重疊、經驗效果提示、手牌重疊、牌區就地展開都與寬螢幕一致（牌堆順序已在 04 完成，兩版共用）
