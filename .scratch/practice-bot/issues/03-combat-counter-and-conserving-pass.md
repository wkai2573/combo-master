# 03：戰鬥反擊評估、動態策略與收招保留

**要建置什麼：**
讓電腦在戰鬥反擊步驟能夠精算攻守差距，判斷是否能達成淨破防 ≥ 3 點之「划算攻擊」以展開連擊；在無法破防時，依據對手威脅程度智慧決策——受傷威脅低（≤ 3 點）時及時「收招保留」手牌，受傷威脅高（≥ 4 點）時以高防招式防守減傷；並依雙方手牌資源差距動態切換策略（我方多 ≥ 2 張時切換全力連擊，否則優先壓縮連擊範圍逼退對手）。
