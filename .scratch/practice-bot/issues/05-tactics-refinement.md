# 05：邊緣牌優先與動態攻防權重戰術精進

**要建置什麼：**
精進單機練習電腦（Heuristic Bot）在先手步驟與反擊步驟之決策啟發式規則：
1. 先手步驟由「中間值優先」改為「手牌密集端之邊緣牌優先」，依手牌招式連擊值重心（`avgCombo`）決定優先出低端邊緣（1～2）或高端邊緣（8～9），避免出中間牌導致後續手牌邊緣牌卡死；同時維持避開 0 攻與 `[先]` 標籤優勢。
2. 反擊步驟導入動態防禦權重（依受傷威脅浮動提升，最高達 2.0）與動態破防攻擊加成（確認破防時每一點溢出攻擊享有 1.5 倍加成）；在對手手牌稀少（我方多 ≥ 2 張）時維持較寬連擊開口以最大化自身出招張數。
