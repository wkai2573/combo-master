# 卡面外框依職業、底色依卡種

## 問題陳述

現在卡面只有一個顏色變數，由卡種決定：招式、裝備、增益、Ex 卡各一色。外框、頂列、卡圖、卡名列、開頭標籤全吃同一個顏色。v0.22.5 把原本的職業色拿掉，理由是整副牌同一個職業時全是同一種顏色，沒有區分性；但朋友建議要有職業色區分。組牌畫面只列共用加自己職業的卡，所以一副牌最多出現兩種職業色，職業色真正的價值是分出共用與職業卡，以及在雙方盤面上認出對手職業。

## 解決方案

卡面拆成兩個通道：外框用職業色，卡面底色與標籤用卡種色。詞彙見 `GLOSSARY.md`。

### 決策摘要

- 外框顏色看職業，卡面其餘（頂列、卡圖、卡名列、開頭標籤）維持看卡種，現有卡種色不變。
- 職業色票沿用 v0.22.5 之前的舊色：共用 `#8a93a8`、劍士 `#e0583f`、盜賊 `#a56ae0`、商人 `#e0b03f`、法師 `#3f8fe0`、弓箭手 `#4fc98b`。共用就是灰色外框。
- Ex 卡不屬於任何職業，是臨時生成的卡：外框與底色都用現有的 Ex 青色。
- 經驗效果生效中的卡，不再改外框顏色，保留職業色；仍保留青色光暈與左下角的小標記。
- 追擊卡的內側線由強調色金改成白色，避免和商人的金色外框混在一起。選取、發光、剛打出用的是外圈或陰影，不動。
- 側欄說明區的大圖與卡面一致：外框用職業色，大圖底色用卡種色，標籤文字維持卡種色。
- 卡牌背面（看不到內容）不動。

## 範圍外

- 追擊卡納入戰鬥區的規則，見 `.scratch/pursuit-in-combat-zone/spec.md`。
- 重新配色或調整卡種色。
- 組牌畫面以外的新篩選或排序功能。

## 測試策略

- 以純函式測職業到顏色的對應，含共用與 Ex 卡的特例。
- 畫面以人工看過各處：手牌、牌區、戰鬥區、經驗區、側欄、組牌畫面、作弊面板。
- 版本號依 `docs/agents/versioning.md`，完成後升 patch 或 minor 由完成者判斷。
