# 03：第 2 課前半，爆發與經驗區（引擎擴充與教學角色）

**要建置什麼：** 課程清單上多出第 2 課「爆發與經驗區」，玩家進入後一開局就在爆發階段：被要求把指定的一張手牌點擊或拖曳到經驗區，看到放進去之後再抽 2 張、經驗區張數增加，並聽到說明：經驗區的卡預設是表側、可以支付費用或提供經驗效果。說明也提到經驗區的其他來源是歸還與增益到期，講完後這一課結束，出現課程結束畫面（歸還的實際示範在下一張票券）。為了做到這件事，章節資料要能預設各區域的內容：棄牌區、怒氣區、經驗區（可指定哪幾張是裏側）、裝備增益區；並能指定起始階段，指定之後的階段照常進行、不再略過抽牌與爆發。這些新欄位全部是選填，第 1 課不需改動。教學腳本要能要求玩家選擇指定的提示選項，教學中可略過的提示一律不顯示「略過」。對手在爆發階段要能不爆發或放一張牌進經驗區，或讓對手手牌為空以避開這個提示，由實作者擇一。新增高亮目標「某一方的經驗區」，電腦版與手機版各自對應畫面元素。新增教學專用角色「修行者」：職業共用，覺醒經驗 8，效果欄「沒有效果」，覺醒欄「（追加）我方總攻擊 +2」，是覺醒中的數值加成、不彈提示；只寫在程式裡，不進卡表、沒有永久編號，依 id 查得到但不出現在任何角色清單。第 2～5 課玩家都用修行者，對手用教官。牌面全部使用真實卡片，沿用 ADR 0008，說明裡的數字由程式帶入。

## Answer

已於 v0.50.2 生效。

- 第 2 課「爆發與經驗區」在 `src/tutorial/lesson2.ts`，已加進 `LESSONS`；伺服器的 `KNOWN_LESSONS` 也加了 2（部署伺服器前這個變更要先上，否則第 2 課的統計事件會被擋）。
- 章節新增選填欄位：`startPhase`（指定後之後的階段照常進行）與 `zones`（雙方棄牌、怒氣、經驗、裝備、增益的預設內容，經驗區可寫 `{ id, covered: true }` 指定裏側）。預設進區域的牌不計入牌組。
- 引擎新增 `burst` 影格（爆發完成），教學腳本用 `{ fx: 'burst' }` 停在這一格；高亮新增 `exp-zone`（電腦版是整個經驗區，手機版是經驗牌堆或對手列的經驗區標籤）。
- 教學封鎖層把可略過的提示改成必選（`gatePrompt` 將 `min` 提到 1），所以爆發階段在教學中沒有「略過」。
- 教學專用角色「修行者」：只寫在程式裡（`tutorialCharacters.ts` 與 `sources/common.ts`），覺醒中總攻擊 +2，不在任何角色清單。
- 對手在爆發階段的提示：這一張票券的腳本到玩家爆發完就結束，對手的爆發提示還沒出現；下一張票券接戰鬥時再用「對手略過」步驟處理。
- 未完成：票券要求的「用瀏覽器在電腦版與手機版各走一遍」（高亮、說明框位置、結束畫面、課程清單、重來）這次沒有做，本環境沒有可用的瀏覽器工具，需要人工在兩種版面確認。
