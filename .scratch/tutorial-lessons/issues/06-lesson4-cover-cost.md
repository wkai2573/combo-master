# 06：第 4 課，蓋 X

**要建置什麼：** 課程清單上多出第 4 課「蓋 X」。玩家一開局經驗區有 8 張表側、已經覺醒，裝備增益區已放著布甲。說明經驗區可以用來支付費用後，玩家被要求出一招，雙方收招，觸發布甲的收招效果。畫面出現「是否發動？（蓋 1）」的確認，玩家被要求按「發動」，動畫停在支付費用的影格，最前面一張表側經驗翻成裏側，總防禦立刻 +1。說明蓋 X 是從最前面依序蓋，裏側的經驗效果無效、只有擁有者看得到，但裏側仍算在覺醒張數內，所以仍是覺醒。新增影格停點「費用支付」與高亮目標「某一方的裝備增益區」。牌面配置要讓布甲在收招時是窗口內唯一可發動的效果，走確認而不是選單。玩家使用修行者，對手用教官，牌面使用真實卡片。

**Blocked by（被誰阻擋）：** 03

**Status：** ready-for-agent

- [ ] 第 4 課出現在課程清單；開局玩家經驗區 8 張表側、已覺醒、裝備增益區有布甲
- [ ] 教學場次測試從頭走到尾：出指定一招、收招後出現費用確認，玩家選「發動」後最前面一張經驗變為裏側、玩家仍為覺醒狀態、總防禦包含布甲的加成；最後進入課程結束畫面並寫入第 4 課完成紀錄
- [ ] 在要求出招與要求確認發動時，選別的、不發動、略過都被拒絕且桌面不變
- [ ] 影格停點「費用支付」可用，高亮「裝備增益區」在電腦版與手機版都找得到對應元素
