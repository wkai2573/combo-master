# 04：第 2 課後半，簡短戰鬥與歸還

**要建置什麼：** 第 2 課在玩家完成爆發之後，不再直接結束，而是接一段簡短戰鬥：雙方各出一招後收招，動畫停在歸還步驟，玩家看到招式卡由最底到最頂、最後才是追擊卡，依序回到經驗區後方，經驗區張數的變化帶入實際數值。說明並提到經驗區主要的增長來源是爆發與歸還。這一課走完才出現課程結束畫面。教學腳本新增影格停點「歸還步驟」。教學腳本能處理爆發階段之後的增益階段與戰鬥階段，讓整段從爆發一路走到歸還都不會跳出沒有被腳本處理的提示。
