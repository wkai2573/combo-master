# 02：流量統計分課

**要建置什麼：** 流量統計的教學事件記下是哪一課。事件資料表新增一個可空的課程欄位，只有教學事件會填；對戰類型仍是單一的「教學」，不另增類型。教學場次依課程送出開始與完成事件，「重來本課」視為重新開始，記一次新的開始。伺服器的事件驗證只允許教學事件帶有效的課程編號，其他事件帶課程欄位要拒絕，不存在的課程編號也要拒絕。既有沒有課程欄位的教學事件，報表一律歸為第 1 課。站長的流量統計報表把教學那一列展開為每課一列，各列顯示開始數、完成數、完成率；總覽、每日、依版本仍不計教學。需要一份資料庫遷移，排在票券 `.scratch/tutorial/issues/06` 的遷移之後；遷移與伺服器部署由站長執行，票券的答案裡要寫明兩個遷移一起部署時的順序不能顛倒。

**Blocked by（被誰阻擋）：** 01

**Status：** ready-for-agent

- [ ] 事件驗證測試：接受教學事件帶有效課程編號；拒絕非教學事件帶課程欄位；拒絕不存在的課程編號；仍拒絕不認得的對戰類型
- [ ] 遷移測試：事件資料表有課程欄位，既有教學事件的課程欄位為空；遷移排在上一個教學遷移之後
- [ ] 教學場次測試：進入某一課送出帶該課編號的開始事件，走到結束畫面送出帶該課編號的完成事件；重來本課送出一次新的開始事件；中途離開不送完成事件；仍不送出戰績
- [ ] 報表測試：舊的空課程事件歸第 1 課；教學那一列展開成每課一列，顯示開始數、完成數、完成率；總覽、每日、依版本仍不計教學
- [ ] 在答案中寫明站長要執行的資料庫遷移與伺服器部署順序，以及部署前送出的帶課程欄位事件會被舊伺服器拒絕這個已知情形
- [ ] 升版並補更新日誌（若無玩家可見變化則依版本規範處理）；`bun run test`、`bun run build` 通過
