# 01：新增播放狀態機並直接測它

**要建置什麼：** 新增 `src/ui/playback.ts` 的 `Playback`，沒有計時器，持有影格佇列與播放狀態，由 `present` 回傳「呈現」。這一票只新增，不改任何使用者。規格見 `.scratch/playback/spec.md`，詞彙見 `GLOSSARY.md` 的「呈現」。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 介面符合規格草圖；`advance` 回傳下一格的停留毫秒（至少 150，乘上速度倍率），佇列空了回 `null`
- [ ] 播放中來新批次接在佇列後面；速度關閉時新批次丟棄；同一個批次編號不重複進佇列
- [ ] `skip` 清空佇列並結束目前播放；`reset` 之後同一批可以再進佇列
- [ ] `present` 是純函式：播放中取影格當下的桌面，紀錄只到該影格當時的長度，提示與等待對象清空；空檔維持上一個顯示的桌面；空檔且沒有上一桌時取新批次第一格；否則取最新真實狀態
- [ ] 數值變化相對上一個顯示的桌面；開局抽牌不算；沒有播放時沒有數值變化
- [ ] 傷害震動的延遲由飛行時序與速度算出
- [ ] `settled` 只在播完且沒有空檔時為真；`settle` 不記空檔的桌面
- [ ] 以上行為由 `tests/playback.test.ts` 直接測，不掛 React、不用假計時器
- [ ] 型別檢查與全部測試通過
- [ ] 純內部新增，依版本號維護規範不升版
