# 手機版面打磨：選單、固定提示欄、牌堆頂牌、直式流程圖

這份規格來自一場完整的盤問，所有決策都已與使用者確認。縮放視窗全黑與追擊飛行卡變大兩個 bug 已於 v0.43.9 修掉，不在這份的待辦裡，只在補充說明記錄原因。新對話請先讀完這份與 `GLOSSARY.md` 的「手機版面」「提示欄」「放置區」「裏側」，再領票券。

## 問題陳述

手機版面上線後，實際玩起來還有一批問題：

- 頂列塞了說明、紀錄、流程圖、速度、離開一排按鈕，佔兩行高度，也容易誤觸離開。
- 戰鬥區忽高忽低。它吃掉所有剩餘高度，而它下面的提示欄在動畫、單一提示、帶卡片選項的提示之間高度都不同，每次切換戰鬥區就跳一次。
- 提示按鈕太小，「發動／不發動」這類二選一很難點準。
- 動畫播放中整條「動畫播放中…／跳過動畫」佔掉底部一塊空間。
- 點卡片看說明會「固定」，要再按取消固定才收；頂列的說明按鈕在觸控上沒有東西可看。
- 回合步驟提示在頂部，離戰鬥區很遠，先手時戰鬥區中央卻一片空白。
- 我方經驗堆與裝備增益堆永遠畫牌背，看不到最上面是什麼。
- 對手條的牌區格子又小又不等寬。
- 拖曳出招的放置區只有我方那一欄，很窄；手機上經驗堆、裝備增益堆當放置區也只有 42×58。
- 經驗區的裏側卡只有半透明遮罩加一個很小的字，和表側幾乎分不出來。
- 戰鬥流程圖是固定橫向版面，手機上縮到看不清，只能拖著捲動。
- 沒有任何錯誤保護：一旦畫面元件拋出錯誤，整片黑。

## 解決方案

- 手機版面的頂列只留「第 N 回合　階段」和一顆三條線圖示的選單鈕，其餘收進選單。
- 提示欄在手機版面固定高度，戰鬥區因此穩定。需要更多空間的提示改用底部面板顯示。
- 手機版面的提示按鈕加大、等寬、必要時分層。
- 手機版面播放動畫時不顯示任何提示條，也不提供跳過；玩家仍可在選單調速度。
- 手機版面點不能操作的卡，從底部滑出說明，點別處自動收起，沒有固定。
- 回合步驟的提示文字搬進手機版面戰鬥區中央，頂部步驟列拿掉。
- 手機版面的經驗堆與裝備增益堆顯示頂牌牌面；對手條五個牌區格子改成等寬加大。
- 拖曳出招的放置區改為整個戰鬥區框，三種版面一致；手機版面的經驗區與裝備增益區改為整排牌堆列。
- 裏側標示全版面加大加醒目，手機版面再更大一檔。
- 戰鬥流程圖在手機版面改用直式單欄排版，全螢幕開啟。
- App 最外層加錯誤邊界，崩潰時顯示說明與復原按鈕。

## 實作決策

**範圍：** 除了標明「三種版面」的項目，其餘只改手機版面（寬 ≤ 640 且直立）。窄螢幕版與寬螢幕版維持原樣。

**頂列與選單**
- 手機版面頂列內容：第 N 回合、階段名稱、三條線圖示的選單鈕。連線異常訊息等既有橫幅不動。
- 選單是從按鈕下方展開的面板，點面板外收起。內容依序：紀錄、流程圖、動畫速度（標準速度、快速、關閉動畫三個選項並排）、作弊模式與作弊面板（僅解鎖時出現）、離開（紅字放最後）。
- 拿掉手機版面的「說明」按鈕。離開維持現狀，不新增確認視窗。
- 選單打開時，按 Esc 先收選單。

**卡片說明**
- 手機版面沿用底部面板元件的樣式，從底部滑出，背後壓暗。內容是現有說明內容，去掉「已固定／取消固定」那一列。
- 點不能操作的卡會打開並顯示那張卡的說明；說明開著時再點另一張不能操作的卡只換內容。
- 點壓暗處只關閉，點擊不穿透。窄螢幕版與寬螢幕版的說明與固定機制不動。
- 觸控的兩段點擊流程不變：能操作的卡第一下預覽、第二下送出。

**回合步驟提示**
- 手機版面拿掉頂部的回合步驟列，提示文字（階段名稱加規則說明加輪到誰）放進戰鬥區中央，位於「範圍」文字上方。「輪到你」「輪到對手」維持醒目色。
- 階段名稱本來就在頂列，所以步驟列整條拿掉。

**提示欄與動畫**
- 手機版面的提示欄固定高度，起始值約 100px，實作時依實際畫面微調。等待對手、處理中、播放動畫都保留同一塊空間，其中播放動畫時不顯示任何文字與按鈕。
- 手機版面不提供跳過動畫。動畫速度仍可在選單裡調整。
- 提示去哪裡顯示改由一條純規則決定：選項按鈕不超過兩顆、沒有不在手牌上的卡片選項、不是排序提示，才顯示在提示欄；否則顯示在底部面板。選項若是牌區裡的牌，既有的自動打開牌區面板行為不變。
- 提示按鈕：每列最多兩顆，等寬各占一半，高度至少約 44px；超過兩顆分層成多列，每列仍等寬。提示欄與底部面板裡的提示共用這套樣式。

**戰鬥區**
- 戰鬥區自己不再因提示欄變化而改變高度。
- 欄位內：招式疊很短時卡放大到幾乎填滿欄寬；疊牌高度依可用高度壓縮，卡多時不被截掉；空欄的「對方／我方」標題與「尚未出招」重新排版，和中央提示不重疊。
- 底部總攻、總防小框的對齊這次不做。

**牌堆**
- 手機版面我方經驗堆顯示頂牌牌面，頂牌取經驗區最後一張。若那張是裏側，我方看到壓暗的牌面，對手看到牌背，遵守牌面可見性。
- 裝備增益堆顯示頂牌牌面，裝備與增益合併排序後取最後一張，順序與打開面板時一致。
- 牌堆頂牌的選取規則是純函式，輸入某位玩家的視角與牌區，輸出要顯示的卡與是否為裏側。
- 對手條沒有牌堆，只有數字格：棄牌、經驗、裝備增益做成等寬加大的按鈕樣式，牌組與怒氣為純顯示，點擊範圍高度至少約 40px。
- 牌堆頂牌顯示牌面會影響卡片飛行的起訖外觀，飛行圖層要確認飛向或飛離這些牌堆時仍正確。

**放置區**
- 出招的放置區改為整個戰鬥區框，包含兩欄、中央與空白，拖曳時整框亮起。三種版面一致。
- 手機版面經驗區與裝備增益區的放置區，改為整排牌堆列；爆發階段與增益階段每次只有一種有效，整列亮起，放在列上任何位置都算那種放置區。
- 提示帶的放置區資訊與連線傳遞不變，只改畫面上的命中範圍。

**裏側標示**
- 全版面統一：「裏側」標籤放大成置中的醒目色塊，牌面壓暗更多，加斜紋底，與牌背質感呼應。
- 手機版面的標示再放大一檔。標籤字級與色塊大小隨卡片尺寸縮放，避免小卡上被切掉。
- `GLOSSARY.md` 的「裏側」條已更新，不需要新的 ADR。

**流程圖**
- 手機版面另排一份直式單欄版面，節點順序與主幹分支不變，全螢幕開啟，不需橫向捲動。主幹仍由共用步驟表產生，保留「你在這裡」標示。
- 排版仍是純函式，沿用既有的流程圖資料結構，新增一種版面方向的選項；既有橫向版面維持原樣。
- 手機寬度以外開啟流程圖仍用橫向版面，不受影響。

**錯誤保護與狀態**
- App 最外層加錯誤邊界。顯示「畫面發生錯誤」，附「重新載入」與「回首頁」兩個按鈕。邊界只攔截畫面元件拋出的錯誤。
- 版面在手機、窄螢幕、寬螢幕之間切換時，把手機版面專屬的暫時狀態（底部面板、選單、說明、自動打開面板的記號）一併收起。對局狀態不受影響。

**版本與日誌**
- 完成一組規格票券升次版號，從 0.44.0 起；各票完成時依版本維護規範升版並補更新日誌，票券底部標記生效版本號。

## 測試決策

好測試只看外部行為：給定輸入，輸出的決策結果，不看元件內部或 CSS。

**接縫（沿用既有，不新增）**
- 提示去向規則：延伸既有的提示面板接縫。輸入對局視角與提示，輸出顯示在提示欄還是底部面板，以及要打開哪個牌區。先例是既有的提示面板測試。
- 流程圖版面：延伸既有的流程圖接縫。輸入版面方向，輸出節點與邊的座標與順序。先例是既有的流程圖測試，沿用它對文字長度、不重疊、分區歸屬的檢查，並新增直式版的寬度上限、主幹順序與「你在這裡」對應。
- 牌堆頂牌選取：新增一個純函式，放在視角層，輸入玩家視角與牌區，輸出頂牌與是否裏側。先例是既有的牌面可見性與視角測試。
- 版面判斷與手牌排版：不變，既有的版面測試維持通過。

**畫面效果**不做自動化 DOM 測試，維持專案慣例。每張票完成後用 Playwright 在 390 與 430 直立手機寬度實測，並確認：
- 在手機、窄螢幕、寬螢幕之間來回縮放不再全黑、也沒有 React 錯誤。
- 提示欄在動畫、單一提示、多選項提示之間切換時，戰鬥區高度不變。
- 拖曳到戰鬥區任何位置、牌堆列任何位置都能出招。
- 追擊翻牌與效果發動時，放大卡與飛行卡的大小都在畫面內。

## 不在範圍內

- 作弊面板的手機版。
- 離開的確認視窗。
- 戰鬥區底部總攻、總防小框的對齊。
- 窄螢幕版與寬螢幕版的選單、說明、提示欄行為（只有放置區與裏側標示是三種版面共通）。
- 自動化的 DOM 與元件測試基礎設施。
- 手機版面的跳過動畫。

## 補充說明

詞彙見 `GLOSSARY.md` 的手機版面、提示欄、放置區、裏側、牌面可見性、招式卡疊、戰鬥區。與 ADR 0003（自己的裏側卡看得到）一致，沒有矛盾。

已修掉的 bug，供票券驗收時回歸比對：
- 縮放視窗全黑：戰鬥區元件用短路方式呼叫兩個版面 hook，版面切換時 hook 數量不一致，整棵樹崩潰。已於 v0.43.9 修掉。
- 追擊成功與效果發動後飛行卡變很大：飛行的複製品卡面寬度寫死，沒跟著外框縮到終點大小。已於 v0.43.9 修掉。

設計來自盤問的 15 個決策加 2 個已修 bug，關鍵取捨：固定提示欄高度優先於彈性高度；複雜提示改用面板而不是撐開提示欄；不提供跳過動畫；放置區以整個戰鬥區框與整排牌堆列為準，不要求精準瞄準。
