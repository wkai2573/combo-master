# 06：觸發窗口機制，先套用到爆發

**要建置什麼：** 新增通用的觸發窗口，並用在爆發後。玩家爆發抽 2 之後，招財貓的額外抽牌、商人的調整順序、覺醒商人的把表側經驗加入手牌三個效果同時可發動時，玩家自己選要發哪個、先發哪個，也可以結束不再發動。這是整組變更中第一個窗口，後續票券沿用它。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** ready-for-agent

- [ ] 引擎有一個通用的窗口機制：收集當下可發動的效果，逐次詢問，每次選一個，結算後重新檢查剩餘效果，直到沒有可選效果或玩家選擇結束
- [ ] 窗口內每個效果最多發動一次；同名的兩張卡算兩個效果
- [ ] 強制效果在清單上標示強制，不能跳過，只能排序；清單上還有強制效果時沒有結束選項
- [ ] 窗口內只剩一個可選效果且沒有強制效果時，維持原本的發動與不發動確認
- [ ] 提示選項顯示效果名稱、卡名、費用與是否強制，以及結束選項；介面與機器人都能正確回應，機器人不會卡住
- [ ] 爆發後的窗口：招財貓可選、商人調整順序可選、覺醒商人加入手牌可選，爆發時與爆發後視為同一個窗口
- [ ] 先攻方先處理完自己的爆發窗口，再換後攻方
- [ ] 重新檢查有測試：招財貓蓋2 在前一個效果之後付不起，就從清單消失；商人先加入手牌導致覺醒狀態改變，後續選項反映最新狀態
- [ ] 測試覆蓋：選擇順序造成不同結果、可以全都不發、強制效果不能跳過、只有一個效果時維持確認、機器人跑完整局不卡住
- [ ] 詞彙表中的觸發窗口條目與實作一致；規則詮釋補上窗口規則
- [ ] 型別檢查、單元測試與機器人壓測通過
