# 09：撰寫規範文件、全卡改寫與規範檢查

**要建置什麼：** 寫出卡片撰寫規範，所有開放的卡與 Ex 卡內嵌行依規範改寫，卡表資料庫與遊戲兩邊的文字一致；卡表網頁多一個「撰寫規範」分頁可以查看；之後卡文不符規範，測試就會失敗。

**Blocked by（被誰阻擋）：** 03、04、05、08

**Status：** ready-for-agent

- [ ] 撰寫規範文件是唯一來源，涵蓋：每行結構順序、時機與條件的句型與連接詞、效果與變數說明的位置、選發效果寫可以、數字與對象稱呼、經驗與表側與裏側與原始的用法、多行與 Ex 卡內嵌行的處理、角色文字只統一用語
- [ ] 全部開放的卡依規範改寫，改寫結果與規格中的對照一致；卡表資料庫與遊戲兩邊的文字一致，待確認標記清除，角色文字統一用語
- [ ] 卡表現有的書寫規範類關鍵字保留，內容縮成一句話加指向規範文件
- [ ] 新增規範檢查測試：掃描全部開放的卡與 Ex 卡行，不符規範就失敗並指出哪張卡哪一行
- [ ] 卡表網頁新增「撰寫規範」分頁，顯示與規範文件同樣的內容，由使用者授權寫入資料庫並重新發佈卡表網頁；重新發佈前先完整讀過現有頁面
- [ ] 規則詮釋的新卡流程加入「依規範檢查並改寫、卡表同步更新」這一步
- [ ] 現有關鍵字測試與資料測試通過，卡文改寫沒有造成關鍵字定義缺漏
- [ ] 型別檢查、單元測試與機器人壓測通過
- [ ] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本
