# 08：覺醒時的效果

**要建置什麼：** 玩家每次由未覺醒進入覺醒狀態時，遊俠可以選擇抽 2；遊俠覺醒仍然獲得第二個瞄準。覺醒是狀態，退出後再達標視為重新覺醒，會再次觸發。

**Blocked by（被誰阻擋）：** 03、06

**Status：** ready-for-agent

- [x] 引擎在每個會改變經驗區張數的步驟之後，偵測各玩家是否由未覺醒進入覺醒
- [x] 進入覺醒時，若該角色有覺醒時效果，就把它放進觸發窗口；若同一步驟已有其他窗口要開，加入同一個窗口，否則自己開一個
- [x] 遊俠：覺醒時可以抽 2，是選發；覺醒仍使瞄準次數多一個
- [x] 經驗區張數掉到門檻以下再回到門檻，會再次觸發；覺醒狀態不變時不會重複觸發
- [x] 角色文字依規格的最終用語更新，卡表資料庫與遊戲同步
- [x] 測試覆蓋：第一次覺醒觸發、不抽、退出再進入再次觸發、與爆發窗口合併、牌組不足時的抽牌
- [x] 規則詮釋補上覺醒規則與角色說明
- [x] 型別檢查、單元測試與機器人壓測通過
- [x] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本

## Answer

已於 v0.17.0 生效。

- 遊戲狀態新增雙方上次偵測的覺醒狀態；開局（含測試改寫區域之後）已覺醒的狀態不算進入覺醒。偵測點：爆發（與爆發窗口合併）、歸還之後、增益階段開始時的增益到期之後；經驗被拿回手牌後退出覺醒，下次偵測會重新武裝。
- 遊俠覺醒時可以選擇抽 2，進覺醒時的窗口（單一可選效果維持確認）。角色文字改為「（追加）當我方覺醒時，可以抽2。獲得【瞄準】。」，卡表資料庫的遊俠覺醒文字已同步並清除待確認標記。
- 偵測在經驗區張數可能變動的步驟之後進行；若在同一個窗口內經驗數先降後升，不會被偵測到，這在目前的卡中不會發生。
- 驗收標準中「牌組不足時的抽牌」沒有另外寫測試：覺醒時的抽牌走通用的抽牌，牌組不夠時抽到沒有為止，沿用既有行為。
