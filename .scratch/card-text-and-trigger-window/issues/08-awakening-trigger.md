# 08：覺醒時的效果

**要建置什麼：** 玩家每次由未覺醒進入覺醒狀態時，遊俠可以選擇抽 2；遊俠覺醒仍然獲得第二個瞄準。覺醒是狀態，退出後再達標視為重新覺醒，會再次觸發。

**Blocked by（被誰阻擋）：** 03、06

**Status：** ready-for-agent

- [ ] 引擎在每個會改變經驗區張數的步驟之後，偵測各玩家是否由未覺醒進入覺醒
- [ ] 進入覺醒時，若該角色有覺醒時效果，就把它放進觸發窗口；若同一步驟已有其他窗口要開，加入同一個窗口，否則自己開一個
- [ ] 遊俠：覺醒時可以抽 2，是選發；覺醒仍使瞄準次數多一個
- [ ] 經驗區張數掉到門檻以下再回到門檻，會再次觸發；覺醒狀態不變時不會重複觸發
- [ ] 角色文字依規格的最終用語更新，卡表資料庫與遊戲同步
- [ ] 測試覆蓋：第一次覺醒觸發、不抽、退出再進入再次觸發、與爆發窗口合併、牌組不足時的抽牌
- [ ] 規則詮釋補上覺醒規則與角色說明
- [ ] 型別檢查、單元測試與機器人壓測通過
