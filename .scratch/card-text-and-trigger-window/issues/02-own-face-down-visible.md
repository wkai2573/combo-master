# 02：裏側經驗只對擁有者顯示牌面

**要建置什麼：** 玩家看得到自己經驗區裏側卡的牌面，畫面上加半透明黑色遮罩標示它是裏側，可以滑過與固定說明；對手只看到牌背。選擇要捨棄的裏側卡時，擁有者看著牌面選。遊戲紀錄不洩漏對手裏側卡的卡名。決策見 ADR 0003，取代 ADR 0002。

**Blocked by（被誰阻擋）：** 無（可立即開始）

**Status：** resolved

- [x] 引擎產生視角時，裏側經驗卡只有在擁有者視角帶牌面，對手視角維持牌背；聯機傳送的視角與影格也一樣
- [x] 選擇裏側卡的提示，對擁有者的選項帶牌面與卡名，不再是只靠位置的盲選
- [x] 介面上擁有者的裏側卡顯示牌面並加半透明黑色遮罩，可以滑過查看與固定說明；對手的裏側卡仍是牌背，不能查看
- [x] 就地展開的經驗區面板也遵守同樣的可見性
- [x] 遊戲紀錄與影格說明不寫出對手裏側卡的卡名，直到卡進入公開區；裏側卡被打開或進入公開區時雙方都看得到牌面
- [x] 卡片飛行對對手視角的裏側卡仍顯示牌背
- [x] 冰霜護甲的捨棄提示改為看著牌面選，經驗區裡的裏側卡發光可點，行為其餘不變
- [x] 現有的覆蓋卡視角測試改寫為新規則：擁有者有牌面、對手沒有、打開後雙方都有、提示選項依視角帶牌面、紀錄不洩漏
- [x] 規則詮釋與 README 中相關說明改寫成新規則與新詞彙，標明 ADR 0003
- [x] 型別檢查、單元測試與機器人壓測通過
- [x] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本

## Answer

已於 v0.11.0 生效。引擎視角與提示選項依擁有者決定牌面；介面對裏側卡加半透明黑色遮罩與「裏側」標記。介面為 CSS 與元件屬性的改動，未以瀏覽器逐項目視驗證，請在對戰畫面確認遮罩的濃度與位置。
