# 07：觸發窗口套用到其餘四處

**要建置什麼：** 回合開始、傷害計算後、收招時、多張經驗卡同時被蓋成裏側這四個時機，也改用觸發窗口。玩家在這些時機同樣可以選要發哪個、先發哪個，強制效果只能排序。

**Blocked by（被誰阻擋）：** 05、06

**Status：** ready-for-agent

- [ ] 回合開始：家族相片可選，凡骨的意志與中毒強制，玩家可自行排序；先攻方先處理完自己的窗口，再換後攻方
- [ ] 傷害計算後：每張復仇之嚎各是一個可選效果，玩家決定發幾張
- [ ] 收招時：冰與雷之曲進入窗口，只有一個可選效果時維持確認
- [ ] 同一次支付費用造成多張經驗卡被蓋成裏側時，蓋反應進窗口，擁有者決定先後，蓋反應是強制所以不能跳過
- [ ] 窗口中發動的效果造成新的蓋反應或其他效果時，新窗口依序處理，不會無限遞迴
- [ ] 現有的回合開始、傷害後、收招、蓋反應相關測試改寫通過，並新增排序與選發的測試
- [ ] 提示標題與動畫影格說明能清楚看出目前是哪個時機的窗口
- [ ] 規則詮釋更新各時機的處理順序說明
- [ ] 型別檢查、單元測試與機器人壓測通過
