# 03：卡表同步與三張新卡進遊戲

**要建置什麼：** 卡表資料庫與遊戲的資料先對齊。卡表關鍵字、特徵、角色文字修正完畢後同步進遊戲，高利貸、狙擊蓄力、熔岩之擊可以在組牌時選用並且能打出，預設牌組不動。這張票不改既有卡的行為，也不套用撰寫規範的改寫。

**Blocked by（被誰阻擋）：** 01、02

**Status：** ready-for-agent

- [ ] 卡表資料庫：關鍵字「起」改名為「先」並更新說明，新增書寫規範關鍵字「經驗」與「原始」，仍寫「覆蓋」「覆蓋狀態」「未覆蓋」的卡文與角色文字改成裏側與表側，電弧的特徵改為法術與雷，清除待確認標記；這些寫入已獲使用者授權
- [ ] 同步卡表到遊戲：新增與更新後的資料、關鍵字、角色數值進入遊戲，同步狀態與版本寫回卡表資料庫
- [ ] 四張商人卡特徵改為貿易；後人後攻回合加成改為總防禦 +1
- [ ] 高利貸：打出時，X 為對方表側且帶 [經] 的經驗張數，對方強制蓋 X，從最前面開始，不足就蓋到沒有為止，被蓋的卡的蓋反應照常觸發
- [ ] 狙擊蓄力：費用蓋4 可選、付得起才詢問，抽2，再選 1 張手牌放到牌組頂
- [ ] 熔岩之擊：費用怒3 可選、付得起才詢問，對方直擊1
- [ ] 三張新卡進入開放清單與組牌卡池，通過牌組驗證；預設牌組不變
- [ ] 每張新卡有測試，覆蓋費用付不起、費用可選、高利貸蓋反應連鎖
- [ ] 關鍵字測試與卡表資料測試通過，沒有任何 [先] 或其他標籤缺定義
- [ ] 規則詮釋的卡片解讀表加入三張新卡與後人的新數值，並改用新詞彙
- [ ] 型別檢查、單元測試與機器人壓測通過
- [ ] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本
