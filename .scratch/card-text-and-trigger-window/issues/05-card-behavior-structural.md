# 05：既有卡行為更新，結構類

**要建置什麼：** 盾擊、凡骨的意志、冰霜護甲三張卡的新行為在遊戲中生效。這三張的更動牽涉到總攻擊計算的順序、強制蓋與裏側卡的捨棄，所以獨立成一張票。

**Blocked by（被誰阻擋）：** 03

**Status：** resolved

- [x] 盾擊：數值為 4/4/6；位於最上方時，戰鬥區每張招式卡若原始攻擊力小於原始防禦力，該卡的攻擊力改為原始防禦力；其餘加成與修正在這之後套用；不含追擊卡，不位於最上方時不生效
- [x] 凡骨的意志：回合開始時蓋前 2 張表側經驗，不足就全蓋；蓋是效果處理而非費用；蓋到自己時這回合的總攻擊與總防禦加成照給，之後它是裏側而失效；一張可蓋都沒有時整個不生效；被前面的效果蓋成裏側時這回合無效
- [x] 冰霜護甲：支付蓋2 後，X 為裏側經驗張數，回復 X，強制捨棄最多 3 張裏側經驗，不足就全捨棄；選擇時看得到牌面
- [x] 每張卡有行為測試，覆蓋盾擊不在最上方、盾擊與其他加成的先後、凡骨表側不足 2 張與蓋到自己、冰霜護甲裏側不足 3 張
- [x] 戰鬥結算的介面顯示（攻守計算）與引擎一致，盾擊的修正會出現在攻擊計算的明細
- [x] 規則詮釋的卡片解讀表同步更新
- [x] 型別檢查、單元測試與機器人壓測通過
- [x] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本

## Answer

已於 v0.14.0 生效。

- 盾擊：位於最上方時，戰鬥區每張招式卡的攻擊力補到至少等於原始防禦力，之後才套用其他加成與修正；追擊卡不算。戰鬥結算明細新增補攻擊力的總增加量欄位，舊的依防禦力加成攻擊的欄位與腳本屬性已移除。
- 凡骨的意志：蓋是效果處理，蓋前 2 張表側經驗，不足就全蓋，蓋到自己加成照給。
- 冰霜護甲：強制捨棄最多 3 張裏側經驗，不足就全捨棄且不詢問。
- 三張卡的卡表文字已依規範改寫（盾擊、凡骨的意志）並清除待確認標記，已重新同步；卡表頁面的同步說明改為目前卡片效果全數實作。介面的攻守計算演出沒有用到被移除的欄位，因此沒有調整。
