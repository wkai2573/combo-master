# 11：作弊模式，單機可用

**要建置什麼：** 單機練習可以隨時開關作弊模式。作弊面板可以從全卡池挑卡加入手牌、移除手牌，並檢視雙方所有牌堆與拖曳調整順序，用來快速建立想測的場面。

**Status：** resolved

- [x] 遊戲物件有一組作弊操作：加入手牌、移除手牌（移出遊戲）、調整某玩家某區域的順序；操作後重新檢查勝負並產生新視角

## Answer

已於 v0.20.0 生效。

- 遊戲物件新增一組作弊操作：加入手牌、移除手牌、調整某玩家某區域的順序，另有讀取雙方全部牌區的檢視。操作者與被操作者分開傳入，連線版可以直接沿用。可加入的卡是全卡池，不含 Ex 卡；可調整順序的區域是牌組、怒氣區、棄牌區、經驗區。操作後重新檢查勝負，每個操作寫進遊戲紀錄，作弊的變化不演動畫。
- 不能動目前提示選項正在引用的卡：引用的手牌不能移除，引用的卡也不能被挪動位置，拒絕時說明是哪張卡。不合法的玩家編號、卡名、順序也一律拒絕，不改動任何東西。遊戲結束後不能再作弊。
- 單機練習的對戰畫面有「作弊模式」開關，開啟時頂端標示，並可開關作弊面板：加入手牌可以搜尋卡名與依職業篩選，移除手牌，牌堆順序可以拖曳或按左右鈕調整。開關只存在那一局的畫面。動畫播放期間面板鎖定，內容停在鎖定前，與桌面對得上。已用瀏覽器實際操作過，窄螢幕沒有橫向捲動。
- 手牌在提示出現之後才加入時，要等下一個提示才選得到；這是提示的選項在出現當下就固定了。連線的作弊模式留給票券 12。
