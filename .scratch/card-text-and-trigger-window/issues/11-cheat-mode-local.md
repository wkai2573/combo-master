# 11：作弊模式，單機可用

**要建置什麼：** 單機練習可以隨時開關作弊模式。作弊面板可以從全卡池挑卡加入手牌、移除手牌，並檢視雙方所有牌堆與拖曳調整順序，用來快速建立想測的場面。

**Blocked by（被誰阻擋）：** 02

**Status：** ready-for-agent

- [ ] 遊戲物件有一組作弊操作：加入手牌、移除手牌（移出遊戲）、調整某玩家某區域的順序；操作後重新檢查勝負並產生新視角
- [ ] 可加入的卡是全卡池，含未開放的卡，不含 Ex 卡；可檢視並調整順序的區域是雙方的牌組、怒氣區、棄牌區、經驗區；戰鬥區、裝備、增益不可動
- [ ] 作弊檢視看得到全部，包含對方手牌、牌組內容與雙方裏側卡
- [ ] 作弊面板有開關，開啟時畫面清楚標示處於作弊模式；開關不存到下一局
- [ ] 加入手牌：面板可搜尋卡名並依職業篩選，選擇後加入自己或對方手牌
- [ ] 移除手牌：面板列出手牌，選擇後移出遊戲
- [ ] 牌堆檢視：面板列出各區內容，拖曳可調整順序；經驗區的順序變動會影響蓋X
- [ ] 任何時候都能操作，動畫播放期間鎖定不可操作；不能動目前提示選項正在引用的卡，拒絕時說明原因
- [ ] 每個作弊操作寫進遊戲紀錄
- [ ] 測試用既有的情境接縫覆蓋：加入手牌、移除手牌、各區順序調整、對提示引用的卡被拒絕、操作後勝負重新檢查
