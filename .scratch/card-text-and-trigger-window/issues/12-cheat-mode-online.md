# 12：作弊模式，連線可用

**要建置什麼：** 與朋友連線對戰時也能開作弊模式。任一方可開、可操作雙方牌區，對方畫面頂端會看到提示，每個作弊操作寫進雙方可見的紀錄。訪客的操作由房主代為執行。

**Blocked by（被誰阻擋）：** 11

**Status：** ready-for-agent

- [ ] 連線協定新增訪客的作弊操作訊息；房主驗證後執行，執行結果與新視角送回訪客
- [ ] 房主與訪客各自可開關自己的作弊面板，面板可操作雙方牌區
- [ ] 任一方開啟作弊模式時，對方畫面頂端顯示對方作弊模式開啟中；關閉後提示消失
- [ ] 每個作弊操作寫進遊戲紀錄，雙方可見，並寫明是誰做的
- [ ] 作弊檢視只對開啟作弊的那一方顯示對方的隱藏資訊，另一方的視角不變
- [ ] 訪客的操作遇到畫面過期或提示正引用該卡時，房主拒絕並回報原因，訪客畫面更新為最新狀態
- [ ] 動畫播放期間在雙方都不能操作
- [ ] 開關不存到下一局，離開房間後重置
- [ ] 測試覆蓋訊息處理：訪客的操作被執行、被拒絕、紀錄寫入；視角依接收者正確
- [ ] 以兩個瀏覽器分頁實際連線驗證
- [ ] 型別檢查、單元測試與機器人壓測通過
- [ ] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本
