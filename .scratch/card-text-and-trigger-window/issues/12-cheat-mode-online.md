# 12：作弊模式，連線可用

**要建置什麼：** 與朋友連線對戰時也能開作弊模式。任一方可開、可操作雙方牌區，對方畫面頂端會看到提示，每個作弊操作寫進雙方可見的紀錄。訪客的操作由房主代為執行。

**Blocked by（被誰阻擋）：** 11

**Status：** resolved

- [x] 連線協定新增訪客的作弊操作訊息；房主驗證後執行，執行結果與新視角送回訪客
- [x] 房主與訪客各自可開關自己的作弊面板，面板可操作雙方牌區
- [x] 任一方開啟作弊模式時，對方畫面頂端顯示對方作弊模式開啟中；關閉後提示消失
- [x] 每個作弊操作寫進遊戲紀錄，雙方可見，並寫明是誰做的
- [x] 作弊檢視只對開啟作弊的那一方顯示對方的隱藏資訊，另一方的視角不變
- [x] 訪客的操作遇到畫面過期或提示正引用該卡時，房主拒絕並回報原因，訪客畫面更新為最新狀態
- [x] 動畫播放期間在雙方都不能操作
- [x] 開關不存到下一局，離開房間後重置
- [x] 測試覆蓋訊息處理：訪客的操作被執行、被拒絕、紀錄寫入；視角依接收者正確
- [x] 以兩個瀏覽器分頁實際連線驗證
- [x] 型別檢查、單元測試與機器人壓測通過
- [x] 依版本號維護規範遞增版本號，並在完成時於本票底部以 `## Answer` 標記生效版本

## Answer

已於 v0.21.0 生效。

- 連線協定新增訪客的作弊訊息：開關自己的作弊模式、作弊操作（帶編號，房主回報結果）。房主一律以連線身分決定操作者，不信任訊息裡的欄位。房主的視角訊息帶雙方的開關狀態，並只在訪客開啟作弊時附上作弊檢視；沒開時訪客收到的資料與以前一樣。
- 作弊的開關、操作與檢視集中在一個中樞，單機與房主共用；房主、訪客、單機的作弊介面共用同一個工廠。開關只存在中樞，下一局重新建立就是關閉，離開房間後重置。
- 任一方開啟時對方畫面頂端顯示「對手開啟了作弊模式」，關閉後消失；開關與每個操作寫進雙方可見的紀錄並寫明是誰做的。訪客操作被拒絕時（過期、提示正引用、不合法）原因回到訪客面板，畫面更新為最新狀態，作弊開關與檢視不會因此被重設。動畫播放期間各自的面板鎖定；房主執行訪客的操作不看房主那邊的動畫，兩邊的畫面都照自己的影格播完再更新。
- 已用兩個瀏覽器分頁透過公開連線服務實際驗證：訪客開啟後房主看到橫幅、訪客在面板看得到房主手牌而房主畫面上訪客手牌仍是牌背、訪客替房主加牌並寫進雙方紀錄、提示正引用的卡被拒絕並說明原因、房主開關後訪客的橫幅出現與消失。
- 測試以假的連線直接驅動房主的訊息處理，覆蓋訪客操作被執行、被拒絕、紀錄寫入與視角依接收者而異。
