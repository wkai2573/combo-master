# 10：卡片文字分段上色

**要建置什麼：** 玩家在卡面、側欄說明與固定說明看到的卡文，依撰寫規範分段上色：回合X次、開頭關鍵字、費用用特殊框，蓋與怒用圖示取代文字並保留數字；時機藍底，條件淡藍底並與時機相連；效果無底色；動作關鍵字維持黃字底線與滑入提示。

**Blocked by（被誰阻擋）：** 09

**Status：** ready-for-agent

- [ ] 文字切分在現有關鍵字切分之上，能把每一行切出回合X次、開頭關鍵字、費用、時機、條件、效果各段，切片還原後等於原文
- [ ] 特殊框：回合X次、開頭關鍵字、費用各自一個框；開頭關鍵字與費用寫在同一組方括號時，畫面上拆成多個框
- [ ] 蓋與怒的費用框用圖示取代文字，保留數字；框內的關鍵字仍可滑入查看說明，鍵盤聚焦也能顯示
- [ ] 時機是藍底，條件是淡藍底並與時機底色相連，效果沒有底色，效果內的動作關鍵字維持現有的黃字底線與滑入提示
- [ ] 多行卡文每行各自上色；Ex 卡內嵌說明行也依規範上色，內嵌標題行維持現有處理
- [ ] 卡面、側欄說明、固定說明、組牌頁的卡文都使用同一套呈現；深色與淺色主題都清楚可讀；窄螢幕不橫向捲動
- [ ] 角色文字不上色
- [ ] 測試覆蓋切分：有回合X次的卡、多行卡、有時機與條件的卡、沒有時機的卡、Ex 卡內嵌行、角色文字不被切
- [ ] 以瀏覽器實際檢查卡面與說明的呈現
- [ ] 型別檢查、單元測試與機器人壓測通過
