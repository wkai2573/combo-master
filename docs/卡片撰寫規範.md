# 卡片撰寫規範

這份規範定義卡片效果文字的標準寫法，讓全卡用語一致。卡表網頁的「撰寫規範」分頁顯示同樣的內容，這份文件是唯一來源。

## 適用範圍

- 所有開放的卡與 Ex 卡的效果文字都要符合這份規範。
- 角色文字不套用句型，也不上色，只統一用語。
- 從卡表更新卡片時，要先檢查文字是否符合規範。不符合就直接改寫，並且卡表上的文字同步更新，讓卡表與遊戲永遠一致。
- 遊戲裡有一個測試掃描全部開放的卡，文字不符合規範就會失敗，並指出是哪張卡的哪一行。

## 每一行的結構

每一行卡文依序由下面幾段組成，沒有的段落就省略。

1. 回合X次：特殊框。寫成 `(回合1次)`，放在最前面。
2. 開頭關鍵字：特殊框。例：`[發]`、`[先]`、`[頂]`、`[追]`、`[經]`。
3. 費用：特殊框。例：`[蓋2]`、`[怒3]`。蓋與怒在畫面上用圖示取代文字，保留數字。
4. 時機：綠底。
5. 條件：藍底，與時機相連。
6. 效果：無底色。
7. 動作關鍵字：效果裡的關鍵字，黃字底線，滑入時顯示提示。例：回復2、直擊3、抽1。

開頭關鍵字與費用寫在同一組方括號裡，以底線相連，後面接全形冒號。例：`[發_蓋2]：`、`[經_怒3]：`、`[蓋1_怒3]：`。開頭關鍵字一定寫在費用前面。畫面上這一組會拆成各自的框。

## 範例

第一個範例，有費用、時機、條件與效果：

```
[蓋3]：當我方收招時，且我方戰鬥區的卡共有特徵「冰」「電」，抽1，回復1。
```

- 特殊框：蓋3
- 綠底：當我方收招時，
- 藍底：且我方戰鬥區的卡共有特徵「冰」「電」，
- 無底色：抽1，回復1。

第二個範例，有回合X次、費用、時機與效果：

```
(回合1次)[蓋2]：當我方追擊判定失敗時，額外翻 1 張卡做追擊判定。
```

- 特殊框：回合1次
- 特殊框：蓋2
- 綠底：當我方追擊判定失敗時，
- 無底色：額外翻 1 張卡做追擊判定。

第三個範例，開頭關鍵字加費用，沒有時機也沒有條件：

```
[發_怒3]：對方直擊1。
```

- 特殊框：發
- 特殊框：怒3
- 無底色：對方直擊1。

第四個範例，多行卡文，每一行各自成一組，各自套用同一套結構：

```
[頂]：我方總攻擊 −3。
[追]：此卡追擊判定失敗。
```

- 第一行，特殊框：頂；無底色：我方總攻擊 −3。
- 第二行，特殊框：追；無底色：此卡追擊判定失敗。

## 時機

- 一律以「當」開頭，以「時」或「後」結尾，後面接逗號。
- 例：當我方收招時、當傷害計算後、當回合開始時、當爆發時、當此卡被蓋為裏側時。
- 效果本身就是時機的標籤，例如 `[頂]`、`[先]`，不需要再寫時機。
- 沒有時機的效果，直接寫效果。

## 條件

- 條件接在時機後面，後面接逗號。
- 有時機時，條件以「且」開頭。例：當傷害計算後，且對方給予的傷害 > 我方給予的傷害，將怒氣區上方 1 張卡加入手牌。
- 沒有時機時，條件以「若」開頭。例：若我方戰鬥區僅有此卡，追擊+1。

## 效果

- 以句號結尾。多個效果以逗號分隔。例：抽1，回復1。
- 變數說明寫在效果最後，格式為 `X＝說明。`。例：抽X，再將 X 張手牌放到牌組底。X＝對方戰鬥區的招式數量。
- 選發的效果，如果沒有費用，動詞前寫「可以」。例：可以調整我方表側經驗的順序。
- 有費用的選發效果，費用本身就表示可選，不再寫「可以」。
- 強制效果不寫「可以」。

## 用語

- 目標對象一律用「我方」「對方」「雙方」，不寫「你」或「敵方」或「對手」。
- 數字一律用阿拉伯數字。例：1 張卡，不寫一張卡。
- 經驗區裡的牌用「表側」與「裏側」描述，不寫「正面」與「覆蓋」。
- 「經驗」指經驗區的卡片。例：表側經驗、裏側經驗。
- 「原始」指卡面印的數值，不含任何效果造成的修正。例：原始攻擊力、原始防禦力。
- 戰鬥階段的第一個步驟叫先手步驟，標籤寫 `[先]`，不寫 `[起]`，也不寫起手。

## 多行卡文與 Ex 卡

- 一張卡有多個效果時，每一行各自成一組，各自套用同一套結構。例：上面的第四個範例。
- 卡文轉述別張卡時，先寫一行單獨的標題，例：`[Ex-中毒]：`，接下來的行屬於那張卡。標題行不做上色。
- Ex 卡本身的卡文也依同一套規範撰寫。

## 角色文字

- 角色文字不套用句型，也不上色。
- 覺醒效果開頭用「（取代）」或「（追加）」標明是覆蓋原效果還是追加在原效果之後。
- 其餘只統一用語：我方、對方、阿拉伯數字、表側與裏側。

## 舊用語對照

- 起手、起手步驟，改為先手、先手步驟。
- `[起]`，改為 `[先]`。
- 覆蓋、被覆蓋、覆蓋狀態，改為裏側、被蓋為裏側。
- 正面、正面向上，改為表側。
- 「各至少 1 張」的條件，改為「共有特徵」。
