# 連擊大師 規則書

本規則書說明連擊大師的完整遊戲規則，適用於遊戲版本 0.22。個別卡片的效果以卡片上的文字為準，文字的寫法見《卡片撰寫規範》。實作時對規則的補充解讀與已確認的細節見《規則詮釋》。

## 一、遊戲概要

連擊大師是兩人對戰的卡牌遊戲。每位玩家有 1 張角色牌和 1 副主牌組，主牌組的張數就是生命值。

- 每回合，雙方輪流打出招式卡。打出的招式連擊值必須接在雙方招式卡疊最後一張招式的連擊值之間，這個限制稱為範圍。
- 招式打完後，雙方以對方的總攻擊力減去我方的總防禦力計算傷害，傷害以牌組頂的牌放進怒氣區的張數表示。
- 打出的卡會進入經驗區，累積經驗可以使用費用較高的效果、打出裝備與增益，並讓角色覺醒。
- 牌組的卡變成 0 張的玩家落敗。

## 二、遊戲元件

### 2.1 角色牌

每位玩家使用 1 張角色牌，角色牌決定：

- 職業：牌組只能放入共用卡與該職業的專用卡。
- 生命值：主牌組必須剛好是這個張數。
- 覺醒經驗：經驗區的卡達到這個張數就進入覺醒狀態。
- 效果與覺醒效果：覺醒效果在覺醒狀態下生效。

角色牌在遊戲開始時公開，不放進牌組，也不會被抽到。目前所有角色的生命值是 50，覺醒經驗是 8。

### 2.2 卡片

卡片分三種類型。

| 類型 | 說明 |
|---|---|
| 招式 | 在戰鬥階段打出。卡面有攻擊力、防禦力、連擊值。 |
| 裝備 | 在增益階段打出，分武器、防具、飾品三個部位。卡面有經驗需求。 |
| 增益 | 在增益階段打出，有持續時間。卡面有經驗需求。 |

每張卡還有職業，是共用或某個職業的專用卡。部分卡有特徵，特徵可以被其他卡的效果引用。沒有特徵也沒有效果文字的招式稱為白板卡。

卡面數值的稱呼：

- 原始數值：卡面印的攻擊力、防禦力、連擊值，不含任何效果造成的修正。
- 總攻擊與總防禦：依戰鬥區的卡與效果計算出的合計值，見第六章。

### 2.3 區域

| 區域 | 說明 |
|---|---|
| 主牌組區 | 存放牌組。順序固定，第一張是最上方。牌組的張數就是生命值。 |
| 手牌 | 只有擁有者看得到。 |
| 招式卡疊 | 戰鬥階段打出的招式，新打出的卡疊在最上方。下方的卡只露出攻擊力、防禦力與連擊值。 |
| 追擊卡疊 | 追擊判定成功的卡，與招式卡疊分開疊放。 |
| 戰鬥區 | 招式卡疊加追擊卡疊。卡效果寫「戰鬥區」時，兩疊都算。 |
| 經驗區 | 存放經驗。卡有表側與裏側兩種狀態，第一張是最前方。 |
| 怒氣區 | 受到傷害時，牌組頂的牌放進這裡，第一張是最上方。 |
| 棄牌區 | 公開區域。 |
| 裝備／增益區 | 存放已打出的裝備與增益。 |

移出遊戲的卡不再屬於任何區域，也不會回來。

## 三、組牌

1. 選擇 1 張角色牌。
2. 主牌組的張數必須等於角色的生命值。
3. 同名卡最多 4 張。
4. 只能放入共用卡與該角色職業的專用卡。
5. Ex 卡是效果產生的臨時卡，不能放進牌組。

## 四、遊戲設置

1. 雙方各自洗勻主牌組，放在主牌組區。
2. 公開角色牌。
3. 隨機決定先攻方與後攻方。
4. 雙方各抽 5 張卡作為起始手牌；角色效果另有規定的，依角色效果。

## 五、回合流程

每回合依序進行下列階段，最後交換先攻方與後攻方。

| 順序 | 階段 | 內容 |
|---|---|---|
| 1 | 重置階段 | 處理回合開始時的效果。 |
| 2 | 戰鬥階段 | 先手步驟、反擊步驟、追擊階段、傷害計算步驟、歸還步驟。 |
| 3 | 抽牌階段 | 雙方各抽 1 張。 |
| 4 | 爆發階段 | 每人可以放 1 張手牌進經驗區並抽 2 張。 |
| 5 | 增益階段 | 每人可以打出 1 張裝備或增益。 |
| 6 | 回合結束 | 交換先攻方與後攻方。 |

雙方都可以選擇是否執行的動作，一律由先攻方先處理，再換後攻方。

### 5.1 重置階段

把橫置狀態的卡改為重置狀態。目前沒有卡使用橫置，這個階段只用來處理回合開始時的效果。

### 5.2 戰鬥階段

1. **先手步驟**：先攻方從手牌選 1 張招式出招。這個步驟沒有範圍限制。如果手牌沒有可打出的招式，先攻方展示手牌，這不算收招。
2. **反擊步驟**：後攻方先，雙方輪流執行下列動作，直到雙方都收招。
   - 選擇 1 張範圍內的招式出招，或收招。
   - 已經收招的玩家不再執行動作，另一方可以繼續出招直到自己也收招。
   - 沒有可打出的招式時，視為收招。
3. **追擊階段**：雙方各翻開牌組頂的卡做追擊判定。
4. **傷害計算步驟**：雙方計算總攻擊與總防禦，並承受傷害。
5. **歸還步驟**：雙方把招式卡疊與追擊卡疊的卡放進自己的經驗區。

特例：後攻方在反擊步驟的第一個動作就收招時，直接進入傷害計算步驟，不做追擊判定。

### 5.3 抽牌階段

雙方各抽 1 張卡。

### 5.4 爆發階段

每位玩家每回合 1 次，可以選擇 1 張手牌放進經驗區，表側。若這麼做，抽 2 張卡。手牌是空的時不能執行。

### 5.5 增益階段

先處理增益的持續時間：每個在場的增益放上 1 個持續時間指示物，指示物數量達到持續時間的增益，放進經驗區。

接著每位玩家每回合 1 次，可以從手牌打出 1 張裝備或增益，條件是自己經驗區的卡數不少於那張卡的經驗需求。增益階段在歸還步驟之後，所以剛歸還的卡也算在經驗區裡。

### 5.6 回合結束

交換先攻方與後攻方，開始下一回合。

## 六、戰鬥細則

### 6.1 範圍

範圍是雙方招式卡疊最後一張招式的連擊值，以及兩者之間的所有數值，兩端都包含。只要任一方的招式卡疊沒有招式，所有連擊值都視為範圍內。

### 6.2 出招

出招是把手牌的 1 張範圍內的招式打到招式卡疊，疊在最上方。出招後，標籤為發的效果在這時處理；在先手步驟打出的招式，標籤為先的效果也在這時處理。先手步驟打出的招式不受範圍限制。

### 6.3 重複連擊值

每位玩家的招式卡疊只能出現一次重複連擊值。

- 同一個連擊值打出第 2 張，是第一次重複，可以打出。
- 招式卡疊已經出現過重複之後，招式卡疊裡已有的連擊值，一張都不能再打出，只能打還沒出現過的連擊值。
- 追擊卡疊不算在招式卡疊裡，所以重複連擊值只看招式卡疊。

例：我方依序出連擊值 8、5、5、3、3、2。第 2 張 5 是第一次重複，可以打出。之後招式卡疊已有 8、5、3，第 2 張 3 不能打出，2 是新的連擊值可以打出。

例：我方 4、對方 5、我方再 4、對方再 5。我方還能出 5，因為 5 對我方是新的連擊值。這時對方的範圍是 5 到 5，但對方已經重複過，5 又已在他的招式卡疊，所以對方不能出牌。

### 6.4 收招

收招代表這個回合不再執行反擊步驟的動作。收招時觸發的效果在這時處理。

### 6.5 追擊判定

追擊階段，先攻方先、後攻方後，各自翻開自己牌組頂的卡。

- 翻到招式卡，連擊值不在範圍內：判定成功，該卡成為追擊卡，放進追擊卡區。
- 翻到招式卡，連擊值在範圍內：判定失敗，該卡加入手牌。
- 翻到裝備或增益：一律判定失敗，加入手牌。
- 任一方招式卡疊沒有招式時，所有連擊值都在範圍內，所以判定必定失敗。

部分效果可以增加翻牌張數或改變判定。

### 6.6 總攻擊與總防禦

- 總攻擊是戰鬥區（招式卡疊加追擊卡疊）所有招式的攻擊力總和，加上效果的修正。
- 總防禦是招式卡疊所有招式的防禦力總和，加上效果的修正。追擊卡疊的防禦力不計算，除非效果另有規定。

### 6.7 傷害計算

我方受到的傷害等於對方的總攻擊減去我方的總防禦。結果不大於 0 就不受傷害。雙方各自計算、同時生效。

雙方的傷害算出來之後，先進入「傷害計算時」：雙方的效果在這時處理，先攻方先處理完自己的窗口，再換後攻方。處理效果時，傷害以當下的數字為準，先發動的效果造成的減免，會影響後面效果的條件。所有效果處理完，才依剩下的傷害承受。

受到 X 點傷害，是從牌組頂把 X 張卡放進怒氣區。牌組張數不足時，放完為止。

### 6.8 歸還

雙方各自把招式卡疊的卡，從最底到最上方，依序放進經驗區最後方，最後才放追擊卡疊的卡。放入的卡都是表側。先攻方先處理，後攻方後處理。

## 七、經驗區與覺醒

### 7.1 表側與裏側

- 經驗區的卡預設以表側進入。
- 表側的卡，雙方都看得到牌面，經驗效果有效。
- 裏側的卡，經驗效果無效。擁有者看得到牌面，對手只看到牌背。
- 裏側的卡翻回表側稱為打開。裏側的卡離開經驗區進入公開區域時，雙方才都看得到牌面。

### 7.2 蓋

蓋 X 是把經驗區的 X 張表側卡轉為裏側。只能從最前方開始依序轉，不能選擇，也不分是不是正在發動效果的那張卡。表側的卡不足 X 張，就不能支付蓋 X。

一次蓋到多張帶有蓋反應的卡時，由卡的擁有者決定它們的處理順序。

### 7.3 覺醒

當我方經驗區的卡數不少於角色的覺醒經驗時，處於覺醒狀態，角色的覺醒效果生效。

覺醒是狀態，不是一次性事件。經驗區的卡減少後可以退出覺醒，再次達標就是重新覺醒，會再觸發「當我方覺醒時」的效果。開局時已經處於覺醒的狀態，不算進入覺醒。

覺醒效果開頭標明取代或追加：取代是覆蓋原來的角色效果，追加是原效果繼續有效，再多一個效果。

## 八、裝備與增益

- 裝備分武器、防具、飾品三個部位，每個部位在裝備／增益區最多各 1 張。同部位已有裝備時，不能再打出。
- 增益可以有很多張，但同名的增益只能有 1 張。
- 增益有持續時間。每個增益階段開始時，增益上放 1 個持續時間指示物；指示物數量達到持續時間，就把該增益放進經驗區。
- 裝備與增益沒有攻擊力與防禦力，不會進入戰鬥區。

## 九、卡片效果

### 9.1 效果文字的讀法

效果文字每一行依序是：回合限制、標籤與費用、時機、條件、效果。例如：

> (回合1次)[蓋2]：當我方追擊判定失敗時，額外翻 1 張卡做追擊判定。

- 回合限制：這個效果每回合最多使用的次數。
- 標籤與費用：寫在方括號裡，標籤決定效果在哪種情形下有效，費用是發動前必須支付的資源。
- 時機：寫成「當……時」或「當……後」，說明效果在什麼時候發動。
- 條件：接在時機後面，以「且」開頭；沒有時機時以「若」開頭。條件不成立，效果不發動。
- 效果：實際發生的事。

一張卡可以有多行文字，每行各是一個獨立的效果。

### 9.2 標籤

| 標籤 | 意義 |
|---|---|
| 先 | 這張招式作為先手步驟的出招時，效果發動。這張卡之後被其他卡蓋住也仍然有效。 |
| 追 | 這張卡成為追擊卡時，效果發動。 |
| 發 | 這張卡打出時，效果發動。 |
| 頂 | 這張卡是招式卡疊最上方的招式時，效果有效；被其他招式蓋住就失效。 |
| 經 | 這張卡在經驗區且是表側時，效果有效；裏側時無效。 |

### 9.3 費用

| 費用 | 意義 |
|---|---|
| 蓋X | 把 X 張表側經驗轉為裏側，才發動後面的效果。 |
| 怒X | 捨棄怒氣區上方 X 張卡，才發動後面的效果。 |

費用不足就不能發動。帶有費用的效果是可選擇的：付得起時，玩家決定要不要發動。沒有費用的效果，除非文字寫「可以」，否則是強制的，條件成立就發動。

### 9.4 常用動作

| 動作 | 意義 |
|---|---|
| 抽X | 從牌組頂抽 X 張卡到手牌。 |
| 回復X | 把怒氣區上方 X 張卡放回牌組頂，等於增加生命值。 |
| 直擊X | 把牌組上方 X 張卡移入棄牌區，不經過防禦計算。 |
| 追擊+X | 追擊判定多翻 X 張牌。 |

### 9.5 觸發窗口

同一時機有多個效果可以發動時，開啟觸發窗口：

1. 先攻方先處理自己的窗口，處理完再換後攻方。
2. 玩家從清單中選擇要發動哪個效果、先發動哪個，也可以選擇結束，不再發動剩下的。
3. 強制效果只能決定順序，不能跳過；清單上還有強制效果時，不能選擇結束。
4. 每個效果在同一個窗口內最多發動一次。
5. 每發動完一個效果，重新檢查剩下的效果能不能發動，例如費用已經付不起了。
6. 清單上只剩 1 個可選擇的效果時，改為單純詢問發動或不發動。
7. 窗口中發動的效果又造成別的效果時，另外開新的窗口處理。

目前使用觸發窗口的時機有：回合開始時、傷害計算時、收招時、被蓋成裏側時、爆發後。覺醒時的效果，若同一步驟已經有窗口，就併入那個窗口。

### 9.6 角色技能

所有角色技能的基礎等級是 LV1。標明升級 X 的效果使該技能的等級 +X，只在本回合有效。等級超過技能的最高等級時，視為最高等級。

## 十、勝負

- 牌組變成 0 張的玩家落敗，即使那是剛抽走的最後一張。勝負在每個不可分割的步驟結束後檢查。
- 雙方同時歸零時，比較手牌張數：多者獲勝，張數相同則平手。
- 連線對戰時，玩家離線超過 30 秒，對手獲勝。

## 十一、角色一覽

| 角色 | 職業 | 效果 | 覺醒效果 |
|---|---|---|---|
| 勇者 | 劍士 | 我方總攻擊含追擊卡、加成前達 15 以上時，總攻擊 +3。 | 取代：總攻擊達 10 以上時，總攻擊 +3。 |
| 後人 | 劍士 | 我方後攻的回合，總防禦 +1。 | 追加：我方後攻的回合，追擊卡的防禦也計入總防禦。 |
| 刺客 | 盜賊 | 此回合每次我方追擊判定成功，總攻擊 +1，上限為 +5。 | 取代：每次追擊判定成功，總攻擊 +2，上限為 +5。 |
| 先人 | 盜賊 | 我方先攻的回合，總攻擊 +X。X 是我方本回合出招張數減 1。 | 追加：我方先攻的回合，追擊判定多翻 1 張牌。 |
| 商人 | 商人 | 爆發後，可以調整我方表側經驗的順序。 | 追加：爆發後，可以將 1 張表側經驗加入手牌。 |
| 法師 | 法師 | 起始手牌為 7 張。 | 追加：抽牌階段，額外抽 1。 |
| 遊俠 | 弓箭手 | 獲得瞄準。 | 追加：當我方覺醒時，可以抽 2，並再獲得 1 個瞄準。 |

### 瞄準

瞄準是遊俠的角色技能，每個瞄準每回合只能使用 1 次，在追擊判定翻牌之前使用。

- LV1：看牌組頂 1 張卡，選擇放在牌組頂或牌組底。
- LV2：先抽 1 張卡，再選擇手牌中的 1 張卡放在牌組頂或牌組底。

遊俠本來有 1 個瞄準，覺醒再多 1 個。部分裝備與卡片可以再增加瞄準的個數或等級。

## 十二、用語對照

| 用語 | 說明 |
|---|---|
| 先攻方、後攻方 | 每回合輪流交換的玩家身分。先攻方在先手步驟先出招，雙方都可選擇的動作也由先攻方先處理。 |
| 先手步驟 | 戰鬥階段的第一個步驟。標籤先只在這個步驟打出的招式上發動。 |
| 表側、裏側 | 經驗區的卡正面向上或向下的狀態。 |
| 蓋、打開 | 蓋是把表側的卡轉為裏側，打開是把裏側的卡翻回表側。 |
| 經驗 | 經驗區的卡。文字裡的表側經驗、裏側經驗就是這個意思。 |
| 蓋反應 | 帶有經驗標籤的卡，在被蓋成裏側的當下觸發的效果。 |
| 觸發窗口 | 同一時機有多個效果可以發動時，由玩家選擇與排序的處理方式。 |
| 範圍 | 可以打出的連擊值區間，見 6.1。 |
| 原始數值 | 卡面印的數值，不含任何修正。 |
| 白板卡 | 沒有特徵也沒有效果文字的招式。 |
| Ex 卡 | 由其他卡片效果產生的臨時卡，不在牌組中，離開經驗區就移出遊戲。 |
