遊戲需求：

1. 角色：1張。  
2. 主要牌組：同名卡最多4張，合計為角色生命值張數。

遊戲設置：

1. 將主牌組洗勻並置於主牌組區。  
2. 將角色牌組公開。  
3. 隨機分配先攻與後攻。  
4. 全部玩家抽5張卡作為起始手牌。

回合流程：以下階段除了戰鬥階段外，皆為雙方同時進行。若雙方玩家同時有可選擇是否執行的動作時，由先攻方先執行在換後攻方。

1. 重置階段：將場上橫置狀態的卡改為重置狀態。  
2. 戰鬥階段：  
   1. 起手步驟：先攻方選擇1張招式卡\#1 出招。(若手中沒有可打出的招式則展示手牌)  
   2. 反擊步驟：後攻方與先攻方輪流重複執行以下動作直到雙方都選擇收招。後攻方先執行。  
      1. 選擇1張招式卡出招或\#2 收招。  
   3. 追擊階段：雙方玩家從自己牌組上翻開1張做為\#3 追擊判定。  
   4. 傷害計算步驟：  
      1. 雙方從牌組上放將X張卡放到怒氣區。X=對手\#4 總攻擊力-我方\#5 總防禦力。  
   5. 歸還步驟：雙方將打出的招式、追擊卡放進持有主的經驗區。（需照順序擺放，最底的放於最前方，最後為追擊卡的最後1張。  
3. 抽牌階段：抽1張卡。  
4. 爆發階段：(回合1次)可以選擇1張手牌放於經驗區，若這麼做則抽2張卡。  
5. 增益階段：(回合1次)可以從手中打出1張裝備卡或增益卡到增益區。  
6. 回合結束：交換先手與後手。

\#1 出招：  
將手中1張\#1.1 範圍內的招式卡打出到戰鬥區。  
打出的卡會疊在已打出的招式卡上方，並使下方的卡僅露出攻擊、防禦、連擊數值。  
此回合若我方尚未出卡則所有卡皆視為範圍內。  
此回合若我方戰鬥區有重複連擊值的卡，則我方不能再打出同連擊值的卡。

\#1.1 範圍內：  
戰鬥區我方最後1張招式卡與對方最後1張招式卡的連擊值與兩卡之間的數值作為可打出的卡片。

\#2 收招：  
此回合我方不再執行反擊步驟的動作。  
此回合若作為後攻方反擊步驟第1個動作，則直接進入傷害步驟。

\#3 追擊判定：執行以下判定。  
追擊判定成功：追擊判定的卡若不在範圍內，則此次追擊判定成功且該卡視為追擊卡。  
追擊判定失敗：追擊判定的卡若在範圍內，則此次追擊判定失敗並將該卡加入手中。

\#4 總攻擊力：  
己方招式卡攻擊力與追擊卡攻擊力總和。

\#5 總防禦力：  
己方招式卡防禦力總和。

卡片說明：  
角色：  
牌組的靈魂核心。使你的牌組組成只能以該職業的卡片與共用卡組成。  
當我方經驗區的卡片≧角色的經驗需求時，視為覺醒狀態。  
覺醒狀態會獲得覺醒效果。

裝備：  
裝備有分為武器、防具、飾品。  
每個分類在裝備／增益區只能有各1張。

增益：  
與裝備不同，在裝備／增益區可以有無數張，但同名只能有1張。  
增益會有持續時間，每當增益階段開始時，會在該卡上放置1個持續時間指示物，當指示物數量≧持續時間值的時候會將該卡放置於經驗區。
