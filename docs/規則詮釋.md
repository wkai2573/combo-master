# 規則詮釋與預設設定

`連擊大師.md` 與 `連擊大師.xlsx` 有些地方沒寫清楚。下面是實作時採用的解讀，**請你確認或指正**。要改的話，大多只要改 `src/engine/combat.ts`、`scripts.ts` 的對應處。

## 一、已由你決定的規則

- 勝負：牌組歸零者落敗。
- 同時歸零：手牌多者勝；手牌相同，雙方洗勻自己的怒氣區並逐張翻開，連擊值大者勝，同值就繼續翻；一方先翻完則落敗，雙方同時翻完則平手。
- 連線：PeerJS 點對點，不做防作弊。

## 二、基本規則的解讀

1. **牌組張數＝生命值。**起始 5 張手牌取自主牌組，所以開局生命值是 45（法師起始 8 張，開局 42）。
2. **牌組只要變成 0 張就落敗**，即使那是剛抽走的最後一張。勝負在每個「不可分割的步驟」結束後檢查（抽牌階段、傷害計算、追擊、爆發、增益、回合結束），所以雙方同時歸零才會走加賽判定。
3. **經驗區的牌預設正面朝上**進入。「蓋X」是把**最前面**的 X 張正面卡翻成覆蓋，且不會蓋到發動效果的卡自己。「打開」是翻回正面。覆蓋中的牌不能發動 [經] 效果。
4. **「重置階段」**目前沒有任何卡使用橫置狀態，所以階段保留但不做事。
5. **起手沒有可出的招式**：展示手牌，不視為收招；之後輪到先攻方時，若手牌出現可出的招式（例如只有 777 時，後續範圍改變）仍可出招。
6. **範圍內**：雙方戰鬥區最後一張招式的連擊值（含）之間。只要任一方戰鬥區沒有牌，就視為全部在範圍內（追擊判定也一樣，所以此時追擊必定失敗）。
   **重複連擊值**（已與你確認）：同一個連擊值在自己的戰鬥區可以打出 2 張，已經有 2 張（＝戰鬥區出現重複）就不能再打同值。例：我 4、對方 5、我再 4、對方再 5，我還能出 5；這時對方範圍是 5～5，但他已有 2 張 5，所以不能出牌。陷阱置於戰鬥區底的牌也算在張數內。
7. **「後攻在反擊步驟第 1 個動作就收招，直接進入傷害步驟」**解讀為連追擊階段一起跳過。手中沒有可出招式而自動收招，也算收招。
8. **追擊判定成功**：翻開的牌不在範圍內。裝備、增益的連擊值視為 0，一定在範圍外，所以翻到它們會成功，但攻擊力是 0。
9. **傷害**＝對手總攻擊 − 我方總防禦，≤ 0 不處理；雙方各自計算、同時生效。
10. **回復 X**：把怒氣區上方 X 張放回牌組頂（生命值增加）。
11. **歸還步驟**：戰鬥區由最底到最頂，最後才是追擊卡，依序加到經驗區最後方。陷阱置於戰鬥區底、陷阱窟置入的卡也一併歸還。
12. **費用**：[蓋X]、[怒X] 的效果都視為「可選」，付得起才會詢問；沒有費用的 [發] 效果則自動發動。
13. **先攻方優先**：雙方都可選擇的動作（爆發、增益、窗口詢問）都是先攻方先、後攻方後，所以沒有「同時隱藏出牌」。

## 三、卡片效果的解讀

| 卡 | 解讀 |
|---|---|
| 3連擊 | 我方出招時，這張（最上方）的連擊值可視為 6、7（原值）或 8，用來判定可出招範圍。重複連擊值的檢查仍用印刷值。 |
| 力量爆破 | 最上方時攻擊 −6（12→6）；翻成追擊判定時一律失敗（回手）。 |
| 戒備打擊 | 成為追擊卡時，防禦力也計入總防禦。 |
| 777 | 不能起手。打出時展示雙方牌頂，連擊值不同（牌頂不存在也算不同）就捨棄這張（從戰鬥區移走）。 |
| 精準追擊 | 最上方時，追擊改為「抽 X、從手牌選 X 張」做判定（X＝追擊數）。 |
| 陷阱變換 | 最上方時，翻到陷阱就放入經驗區，再從經驗區（含覆蓋中）選 1 張陷阱直接成為追擊卡（視為成功）。 |
| 先祖圖騰 | 最上方時防禦 +2。我方為先攻時，正面朝上的它可從經驗區當招式打出（受範圍與重複連擊值限制）。 |
| 式不過3 | 「第 4 張」指本回合對手的**出招張數**為 4（陷阱置底不算）。對手的 [發] 先處理完，才詢問你；捨棄這張與 1 張手牌，並把該招式捨棄。 |
| 陷阱 3~7 | 對手打出連擊值為 N 的招式後（對手的 [發] 先處理）可蓋 1 經驗（不含它自己），把它放在我方戰鬥區底；之後它算戰鬥區的牌。若此時戰鬥區只有它，它會成為「最後一張」，影響範圍。 |
| 陷阱投擲／回收／窟 | 陷阱投擲：手中必須放 1 張陷阱到經驗區（沒有就略過）。陷阱窟：經驗區攻擊力 ≤ 2 的陷阱（含覆蓋中）全部置於戰鬥區底。 |
| 驚嚇陷阱 | 成為追擊卡時：先選經驗區 1 張加入手中，再選手中 1 張陷阱放入經驗區（兩步都是必選，沒有對象就略過）。 |
| 誘餌圖騰 | 追擊階段開始時、正面朝上才能發動：捨棄它並蓋 3 張**其他**正面經驗，對手此回合追擊 −1（最少 0）。 |
| 黑暗詛咒 | 它在最上方時，對手之後打出的每張招式，對手要覆蓋自己經驗區最前面的 1 張正面卡。 |
| 降級詛咒 | 蓋 2＋怒 5 後，雙方各自選自己 1 張經驗（含覆蓋）捨棄。 |
| 煉金印記／狙擊印記 | 只影響**之後**打出的招式（不含自己）。狙擊印記的「持有[發]」指有打出時效果的招式；「抽怒氣卡」＝怒氣區最上方 1 張加入手牌，再捨棄 1 張手牌。 |
| 必殺一擊 | 覺醒時才會詢問；怒 10，本回合追擊 +1。 |
| 吸血打擊 | 最上方時，傷害計算後回復 ⌊我方造成的傷害 ÷ 3⌋。 |
| 不變應萬變 | 最上方且對手受到的傷害較多時，回合結束不交換先後攻。 |
| 金手鐲 | 爆發階段開始時蓋 2；之後爆發仍須放 1 張手牌進經驗區，但抽牌改為抽 3。 |
| 月光劍 | 增益階段開始時，打開 1 張覆蓋的經驗卡（有的話必做）。 |
| 兔腳項鍊 | 每回合 1 次，追擊判定失敗時可蓋 2，從牌組額外翻 1 張判定（額外這張不再觸發兔腳）。 |
| 慢速治癒 | 增益階段開始時：放 1 個指示物 → 回復 2 → 若指示物 ≥ 持續時間（4）就放入經驗區。所以共觸發 4 次。 |
| 替身 | 每 1 點傷害，若有覆蓋中的經驗就捨棄 1 張代替（自動發動，沒有選擇）。 |
| 裝備／增益通則 | 經驗區張數 ≥ 經驗需求才能在增益階段打出（增益階段在歸還步驟之後，所以包含剛歸還的牌）；同部位已有裝備時不能再打出；同名增益只能 1 張；每回合 1 次。 |

### 角色

| 角色 | 解讀 |
|---|---|
| 勇者 | 「總和攻擊」指加成前的總攻擊（含追擊卡）；≥ 15（覺醒 10）時 +3。 |
| 刺客 | 每次追擊判定成功 +2（覺醒 +4）；多次成功累加。 |
| 商人 | 所有「抽」的動作（抽牌階段、爆發、抽X）都改為「看上方 2 張選 1 張，另一張放牌底」；起始手牌與抽怒氣不受影響。覺醒：計算攻擊時手牌 > 3 張 +3。 |
| 法師 | 起始手牌 8 張。覺醒：抽牌階段額外把怒氣區上方 1 張加入手牌。 |
| 先人 | 先攻回合攻擊 +（出招張數 − 1）；覺醒：先攻回合追擊 +1。 |
| 後人 | 後攻回合總防禦 +2；覺醒：後攻回合追擊卡的防禦力也計入。 |
| 弓箭手 | xlsx 該列是空的，所以只顯示「待補」，不能選用也不能組牌。 |

## 四、職業歸屬與預設牌組（我的提案）

特殊招式在 xlsx 沒有職業，我依風格分配（`src/data/classMap.ts`）：

- **劍士**：吸血打擊、戒備打擊、必殺一擊、3連擊、先祖圖騰、不變應萬變
- **盜賊**：陷阱 3~7、陷阱投擲、陷阱回收、驚嚇陷阱、陷阱變換、陷阱窟、狙擊印記、誘餌圖騰
- **商人**：布局、煉金印記、精準追擊、式不過3、777
- **法師**：力量爆破、黑暗詛咒、降級詛咒
- **共用**：36 張花色招式、快速治療（刻意設為共用，商人和法師都能用）、全部裝備與增益

預設牌組（`src/data/presetDecks.ts`）每位角色 50 張，核心卡 12~17 張，再用共用招式補滿；測試保證都合法，且連擊值 1~9 都有。想調整只要改 `core`（專用卡張數）與 `fill`（共用招式優先順序）。

## 五、已知限制

- 斷線只做「離線 30 秒判負」，沒有重連回原局。
- PeerJS 使用公開 broker，雙方網路較嚴格時可能連不上（沒有 TURN）。
- 單機練習的對手是「偏積極的隨機機器人」，不是 AI。
- 卡面沒有插圖，只有文字卡框。
- 平衡尚未調整。隨機機器人互打的勝率只能當冒煙測試，不能反映真人對戰強弱。
