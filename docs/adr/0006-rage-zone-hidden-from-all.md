# 怒氣區的牌面任何人都不能查看，連擁有者也不行

怒氣區的張數公開，牌面對雙方都隱藏。引擎產生視角時，怒氣區的牌一律不帶牌面，提示選項、影格與聯機傳送也一樣；牌離開怒氣區進入公開區（例如捨棄進棄牌區）或手牌時，才看得到牌面。原本只有擁有者看得到，改掉是因為怒氣區是被動承受傷害堆出來的，擁有者看得到順序會讓付怒與回復變成可預測的算計，隱藏後它才是單純的血量資源。

## 考慮過的選項

- **只有擁有者看得到（原本的規則）**：擁有者能規劃付怒與回復會取到哪張，資訊多但讓怒氣區變成另一個可以研究的牌區，介面也要維護查看列表。
- **誰都看不到（採用）**：規則只有一條，介面不必提供怒氣區的列表。

## 後果

- 作弊檢視不受限制，仍能查看與調整怒氣區的順序。
- 介面上怒氣堆不再可點，手機版面板也沒有怒氣區分頁；怒氣堆的張數與增減變化照常顯示。
- 付怒 X、洩憤等把怒氣區的牌捨棄進棄牌區的效果，牌是進了公開區才讓雙方看到；復仇之嚎把怒氣區的牌加入手牌，只有擁有者在手牌裡看得到。
- 遊戲紀錄不能寫出怒氣區的卡名，直到卡進入公開區或手牌（手牌的內容對手本來就看不到）。
