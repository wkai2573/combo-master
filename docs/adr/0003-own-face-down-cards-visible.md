# 裏側的經驗卡只對擁有者顯示牌面，對手只看到牌背

經驗區裡裏側的卡，擁有者看得到牌面（畫面上加半透明黑色遮罩標示裏側），對手只看到牌背。引擎產生視角時，裏側卡只有在擁有者視角才帶牌面；選裏側卡的提示選項同樣只對擁有者帶牌面。取代 ADR 0002「雙方都隱藏」，因為擁有者必須自己記得蓋了什麼，卻沒帶來有意義的不確定性，且與「可以確認我方裏側經驗」的需求不符。

## 考慮過的選項

- **雙方都隱藏（ADR 0002）**：裏側是真正的隱藏資訊，連擁有者也只能靠記憶，冰霜護甲只能盲選。代價是擁有者記憶負擔大、介面無法提供裏側卡的說明。
- **擁有者平常看到「?」，要按查看才顯示牌面**：保留一點記憶成分，但多一道操作，實際上沒有擋住任何資訊。
- **擁有者永遠看得到牌面（採用）**：規則只有一條，視角依擁有者判斷，沒有額外的查看動作。

## 後果

- 視角、聯機傳送的影格、提示選項都要依視角者是否為擁有者決定要不要帶牌面；對手視角仍不能帶裏側卡的牌面。
- 冰霜護甲改為看著牌面選擇要捨棄的裏側卡。
- 遊戲紀錄不能寫出對手裏側卡的卡名，直到卡進入公開區。
