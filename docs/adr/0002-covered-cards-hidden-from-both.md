# 覆蓋的經驗卡對雙方都隱藏，視角規則不分自己與對手

經驗區裡覆蓋的卡，在雙方的視角都只有牌背，連擁有者自己也不能查看牌面。引擎產生視角時，只要卡是覆蓋狀態就不帶牌面，不再區分是誰的牌；卡片效果若明確允許查看，再為那張卡加專屬的查看提示。覆蓋的卡離開經驗區進入公開區（例如被捨棄進棄牌區），或被打開翻回正面時，才會公開。

## 考慮過的選項

- **只對對手隱藏**：擁有者看得到自己覆蓋的卡，實作單純，也是原本的行為。但這讓「覆蓋」變成只有單向的隱藏，擁有者永遠知道全部資訊，覆蓋失去不確定性，也和冰霜護甲這類「選覆蓋的卡捨棄」的設計意圖不合，因為它們該是盲選。
- **雙方都隱藏（採用）**：覆蓋就是隱藏資訊，規則只有一條。代價是擁有者要自己記得蓋了什麼，介面也不能提供覆蓋卡的說明。

## 後果

- 視角、聯機傳送的影格、提示選項都不能帶覆蓋卡的牌面；選覆蓋卡的提示只能依位置盲選。
- 日後出現允許查看覆蓋卡的效果時，需要新的通道把牌面只傳給有權查看的一方，視角規則本身不放寬。
