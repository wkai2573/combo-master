# 新手教學以真實引擎驅動並由測試把關

新手教學跑的是真正的遊戲引擎：雙方的角色、手牌與牌組固定，對手照腳本出招，介面在指定的影格停下來顯示說明。卡片數值直接用卡表同步來的數值，不另外寫死一份；另外有一個測試把教學從頭跑到尾，確認每一步腳本指定的出招都合法，最後是玩家獲勝。

## 考慮過的選項

- **預先錄好的演示，數值寫死**：不受卡表影響，但教學裡的卡會跟實戰的卡長得不一樣，新手學到的數字是錯的；規則改了，演示也不會跟著變。
- **真實引擎，數值跟卡表連動（採用）**：教學顯示的數值、範圍判定、追擊與傷害都和實戰一致；代價是卡表改了白板卡的數值，教學可能就打不贏或某一步出招不合法。

## 後果

- 卡表同步若讓教學失效，教學測試會失敗。這時要調整教學的牌面配置，不是把數值改回來。
- 說明文字裡的攻防與傷害數字由程式依實際數值帶入，不寫死在腳本裡。
