# 只有網站建置要用的圖片進 git

無框原圖、成品卡面與各種製作過程的圖片反覆更新，讓打包後的 repo 膨脹到約 2 GB。現在只有網站建置要用的圖片進 git：`public/`、分層卡面的插畫 `src/cardLayout/portraits/` 與兩個卡框目錄。其他圖片只留在製作者的電腦上。`.gitignore` 預設忽略圖片格式，再逐一放行上述位置。

既有歷史中的其他圖片已用改寫歷史的方式清除；放行位置裡的舊版本也一併清除，只保留清理當下的版本。

## 考慮過的選項

- **只停止追蹤，不改寫歷史**：commit 不會改變，但 repo 大小不會下降。
- **所有圖片都移出 git**：正式站由 CI 從 git 內容建置，必須另外架設圖片儲存並修改部署流程。
- **只忽略當時存在的幾個圖片目錄**：擋不住之後新增的中間產物目錄。

## 後果

- 只留本機的原圖沒有遠端備份，要由製作者自行保存。新 clone 的專案裡沒有這些檔案。
- 新增網站要用的圖片位置時，要同步在 `.gitignore` 放行。沒放行的圖不會進 git，建置也不會報錯，線上站只會缺圖。
- 清理前的 commit SHA 大多已經失效，先前記下的 SHA 在目前的歷史裡找不到。切回舊 commit 時畫面會缺圖。
