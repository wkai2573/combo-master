# 卡牌插畫與卡面共用規格

所有現有與未來卡種共用本規格，包括招式、裝備、增益、角色與 Ex 卡。各卡種的檔名採用自己的永久編號。

## 無框插畫

交付直式 **1162 × 1395、8-bit sRGB PNG**。插畫滿版，主體集中在畫面中段偏上，下方留較安靜的背景。卡框、卡名、數值和效果文字由卡面合成處理。招式無框插畫存於 `portrait-card-art/`，按職業、共用與白板分目錄，檔名使用 `A編號-卡名.png`。

## 效果區排版

- 卡名與效果內文統一使用 **Noto Sans TC、字重 700**。在 **1260 × 1760 px** 的成品畫布上，效果內文字級為 **70 px**。
- 卡名依各自的卡名框等比放大，以實際筆畫的寬度與高度判斷可容納的最大字級，置中並保留適當留白。
- 效果區底緣距卡名框上緣約 **13 px**，多行內文往上延伸。
- 標籤用深藍色底配白字。
- 蓋 X 費用用黑底、白圓、黑色數字。
- 怒 X 費用用紅色火焰、白圓、黑色數字。
- 動作用 **`#FF7D1F`** 橘色六角形配黑字，數值放在同一個六角形內，例如「抽1」。
- 名詞用同一個 **`#FF7D1F`** 橘色六角形配白字，例如「元素」與「+X+Y」。
- 使用時機用黑字，文字下半部襯淺藍色。
- 使用條件用黑字，文字下半部襯淺綠色。
- 費用標記、關鍵字與同一行正文依共用效果版式對齊基線。以「戒備打擊」的基線修正（`ab87e87`）與其後統一的招式卡面版式（`95e1c3f`）為參考。
- 效果區沿用核定成品的半透明底色，合成後對照成品確認底圖透出的程度和文字可讀性。「復仇之嚎」的半透明底色見 `7d33565`，四成是早期預覽（`12737e6`）的紀錄。

## 光線與色彩

- 整體明亮通透。用柔和的日光或環境補光提亮中間調和陰影，保留深色線稿與主體輪廓。室內、夜色和洞窟可保有場景氣氛，人物與重要道具仍要清楚可辨。
- 保留各物件原有的色相，降低霓虹般的黃綠、青藍、紫紅與魔法光效。背景多用淺石色、奶油色、柔藍和灰綠，主體可以稍濃以維持焦點。避免灰霧、褐色濾鏡和過曝白斑。
- 重調既有插畫時保留構圖、角色姿勢、表情、物件與招式辨識特徵，優先調整光線和色彩。新圖沿用清楚的線稿、柔和賽璐珞上色與 Q 版奇幻風格。

## 白板招式

A1–A36 共用明亮庭院與開啟的寶箱。畫面無人物，箱內只放牌面花色對應的寶石，依牌面數字放 1–9 顆。黑桃用灰藍、紅心用柔粉紅、梅花用灰綠、方塊用琥珀金。寶石互不遮擋，縮小後仍看得清形狀及顆數。
