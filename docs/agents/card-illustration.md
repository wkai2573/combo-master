# 招式插畫規格

正式無框插畫存於 `portrait-card-art/`，按職業、共用與白板分目錄。交付直式 **1162 × 1395、8-bit sRGB PNG**，檔名使用 `A編號-卡名.png`。插畫滿版，主體集中在畫面中段偏上，下方留較安靜的背景。卡框、卡名、數值和效果文字由卡面合成處理。

## 光線與色彩

- 整體明亮通透。用柔和的日光或環境補光提亮中間調和陰影，保留深色線稿與主體輪廓。室內、夜色和洞窟可保有場景氣氛，人物與重要道具仍要清楚可辨。
- 保留各物件原有的色相，降低霓虹般的黃綠、青藍、紫紅與魔法光效。背景多用淺石色、奶油色、柔藍和灰綠，主體可以稍濃以維持焦點。避免灰霧、褐色濾鏡和過曝白斑。
- 重調既有插畫時保留構圖、角色姿勢、表情、物件與招式辨識特徵，優先調整光線和色彩。新圖沿用清楚的線稿、柔和賽璐珞上色與 Q 版奇幻風格。

## 白板招式

A1–A36 共用明亮庭院與開啟的寶箱。畫面無人物，箱內只放牌面花色對應的寶石，依牌面數字放 1–9 顆。黑桃用灰藍、紅心用柔粉紅、梅花用灰綠、方塊用琥珀金。寶石互不遮擋，縮小後仍看得清形狀及顆數。
